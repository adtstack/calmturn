# 시계 (부부싸움 시리즈) v4

## 한 줄 정의
`시계 (부부싸움 시리즈)`는 부부싸움 중 두 사람이 **같은 총 발언시간**을 갖고, 정해진 **턴당 발언 제한시간** 안에서 번갈아 말하도록 돕는 가장 단순한 대화 시계입니다.

## v4 원칙
1. **UI는 최대한 단순하게 둔다.**
   - 시작 전에는 이름, 첫 발언자, 각자 총 발언시간, 턴 제한만 고른다.
   - 실행 중에는 화면 터치로 차례를 넘기고, 버튼은 `일시정지`와 `종료`만 둔다.
   - 종료는 확인창에서 한 번 더 묻는다.

2. **공평함은 같은 총 발언시간이다.**
   - 기본 참가자 이름은 `남편`과 `와이프`다.
   - 각자 총 발언시간 프리셋은 `10 / 20 / 30 / 60분`이다.
   - 턴 제한 기본값은 `30초`이다.
   - 턴 제한 프리셋은 `10초 / 30초 / 45초 / 1분`이다.

3. **고급설정은 시작 화면 밖으로 숨긴다.**
   - 시작 화면 우상단 톱니바퀴에서 고급설정으로 들어간다.
   - 고급설정에는 오버타임, 알림, 패널티 기록, 세부 시간 규칙을 둔다.
   - 별도 저장 버튼은 두지 않고, 뒤로 가면 유효한 설정을 자동 저장한다.

4. **패널티는 표시하지 않는다.**
   - 기존 패널티 기록 기능은 내부 데이터로 유지한다.
   - 실행 화면과 기본 기록 화면에는 패널티/주의 표시를 노출하지 않는다.
   - 앱은 누가 잘못했는지 판단하지 않는다.

## 실행 화면
실행 화면은 가로 2분할 시계입니다.

- 왼쪽은 첫 번째 참가자, 오른쪽은 두 번째 참가자다.
- 양쪽의 시작 폭은 50:50이다.
- 한 사람이 말하면 그 사람의 총 남은 시간이 줄어들고, 남은 시간 비율만큼 화면 영역도 줄어든다.
- 상대 영역은 그만큼 넓어져 경계선이 말하는 사람 쪽으로 이동한다.
- 각 영역 전체가 차례 넘기기 터치 영역이다.
- 상단 버튼은 `일시정지`와 `종료`만 둔다.

## 화면 흐름
0. **시작/설정**
   - 기본값 또는 마지막으로 저장한 설정을 보여준다.
   - 이름, 첫 발언자, 각자 총 발언시간, 턴 제한을 정하고 바로 시작한다.

0-1. **고급설정**
   - 오버타임, 알림, 패널티 기록, 세부 시간 규칙을 조정한다.
   - 뒤로 가면 자동 저장한다.

1. **실행**
   - 가로 반반 타이머를 보여준다.
   - 화면 터치로 차례를 넘긴다.
   - `일시정지`와 `종료`만 표시한다.

2. **종료 후**
   - 대화시간을 요약한다.
   - 총평과 해시태그를 입력한다.
   - 결과는 `잘 마무리됨` 또는 `아직 남음`으로 기록한다.

3. **기록 달력**
   - 날짜별 O/X 결과를 보여준다.
   - 날짜 아래에는 최대 3개까지 표시한다.

4. **일자별 기록**
   - 해당 날짜의 기록을 3-4개 정도 자연스럽게 볼 수 있는 목록으로 보여준다.

5. **기록 상세**
   - 각 기록의 시간, 총평, 해시태그, O/X, 참가자별 사용 시간을 보여준다.

## 데이터와 호환성
- 새 기록 필드: `summaryText`, `tagsText`, `outcome`
- `outcome` 값:
  - `resolved`: 잘 마무리됨, 달력 표시 `O`
  - `unresolved`: 아직 남음, 달력 표시 `X`
- 기존 로컬 기록은 새 필드가 없어도 그대로 읽는다.
- 녹음, 마이크, 감정 분석, 클라우드 동기화는 v4 범위에 없다.
