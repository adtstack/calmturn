# 07. Safety, Ethics & Privacy

## 1. 핵심 원칙
말차례는 민감한 대화에서 사용될 수 있으므로 안전·동의·개인정보를 제품의 중심에 둔다.

## 2. 반드시 지켜야 할 원칙
1. 양쪽 동의 없이 시작하지 않는다.
2. 한 사람이 멈추고 싶으면 멈출 수 있다.
3. 몰래 녹음하지 않는다.
4. 몰래 공유하지 않는다.
5. 앱이 누가 맞는지 판단하지 않는다.
6. 위험하거나 폭력적인 상황에서는 사용을 중단하라고 안내한다.
7. 치료·진단·상담 효과를 보장하지 않는다.

## 3. MVP 개인정보 방침
### 수집하지 않는 것
- 음성 녹음
- 위치 정보
- 연락처
- 사진
- 건강 정보
- 광고 추적 ID

### 저장하는 것
- 세션 날짜
- 참가자 별칭
- 각자 사용한 시간
- 사용자가 직접 입력한 회고 메모

### 저장 위치
- 기본: 사용자 기기 내부
- 서버 전송 없음
- 클라우드 동기화 없음

## 4. 개인정보 UX
- 첫 온보딩에서 “기본적으로 기록은 이 기기에만 저장됩니다”라고 안내한다.
- 기록 삭제 버튼을 명확히 제공한다.
- 사용자가 입력한 메모는 민감할 수 있으므로 공유 기능을 MVP에서 제외한다.

## 5. 안전 문구
### 온보딩
“말차례는 대화 시간을 나눠주는 도구입니다. 관계를 진단하거나 치료하지 않습니다.”

### 동의 화면
“두 사람이 모두 원할 때만 시작하세요. 불편하거나 위험하다고 느껴지면 언제든 멈출 수 있습니다.”

### 휴식 화면
“지금은 해결보다 진정이 먼저일 수 있어요. 잠깐 쉬어도 괜찮습니다.”

### 종료 화면
“오늘 여기까지 해도 괜찮아요. 다음에 다시 이어갈 수 있습니다.”

## 6. 위험 상황 대응
앱은 위험·폭력·협박 상황에서 대화를 계속하도록 유도하면 안 된다.

권장 문구:
“신체적 위험, 협박, 강요가 느껴진다면 앱 사용을 중단하고 안전한 곳으로 이동하거나 주변의 도움을 받으세요.”

## 7. App Store 리스크 줄이기
- “치료한다”, “관계를 고친다”, “싸움을 해결한다” 같은 보장 표현 금지
- “심리 분석”, “감정 진단” 표현 금지
- 건강/의료 앱처럼 보이는 카테고리와 문구 회피
- 사용자 생성 콘텐츠를 온라인에 올리는 기능은 MVP에서 제외
- 고객 지원 연락처와 개인정보 처리방침 제공

## 8. 향후 AI 기능을 넣을 때의 원칙
AI 요약이나 감정 분석은 아주 조심해야 한다.

조건:
1. 양쪽 명시적 동의
2. 어떤 데이터가 전송되는지 명확히 설명
3. 끌 수 있는 옵션
4. 삭제 가능
5. 판단/진단 금지
6. “AI 요약은 틀릴 수 있음” 안내

권장:
- v1.0에는 AI를 넣지 않는다.
- v1.2 이후 실험 기능으로만 검토한다.

## 9. 금지 기능 목록
- 몰래 녹음
- 상대방 평가 점수
- “누가 더 잘못했는지” 판정
- 감정 조작성 알림
- 대화 내용을 외부에 자동 공유
- 상대의 앱 사용 내역 감시
- 한 명이 다른 사람의 기록을 원격 삭제/수정

## 10. 제품 철학
좋은 대화 도구는 사람을 통제하지 않는다. 말차례의 목적은 대화를 강제로 계속하게 하는 것이 아니라, 계속할 수 있을 때 더 안전하고 공평하게 말하도록 돕는 것이다.
