# 07. Safety, Ethics & Privacy - v4

## 핵심 원칙
`시계 (부부싸움 시리즈)`는 대화 시간을 나누는 도구다. 앱은 누가 옳은지, 누가 잘못했는지, 관계가 어떤 상태인지 판단하지 않는다.

## 안전 원칙
1. 앱 사용을 강요하는 표현을 쓰지 않는다.
2. 상담, 치료, 화해 보장을 암시하지 않는다.
3. 패널티/주의 표현을 실행 화면과 기본 기록 화면에 노출하지 않는다.
4. 결과값은 `잘 마무리됨`과 `아직 남음`으로만 표현한다.
5. 종료는 확인창을 거쳐 실수를 줄인다.
6. 저장하지 않고 마칠 수 있어야 한다.

## 개인정보 원칙
앱은 v4 범위에서 다음을 수집하지 않는다.

- 음성
- 녹음 파일
- 마이크 입력
- 위치
- 연락처
- 계정 정보
- 서버 전송 데이터

## 로컬 저장 데이터
앱은 사용자가 직접 만든 기록만 로컬에 저장한다.

- 시작/종료 시간
- 참가자 이름
- 시간 사용 결과
- 총평
- 해시태그
- 결과값
- 내부 호환성용 패널티 카운트

## 사용자 문구 기준
- “앱은 누가 맞는지 판단하지 않습니다.”
- “기록은 다음 대화를 위한 메모입니다.”
- “녹음, 마이크, 감정 분석은 v4 범위에 없습니다.”
- “저장하지 않고 마칠 수 있습니다.”

## Google Play 리스크
피해야 할 표현:

- 부부싸움을 해결합니다.
- 관계를 치료합니다.
- 상대의 잘못을 기록합니다.
- 감정을 분석합니다.
- 대화 내용을 이해합니다.

권장 표현:

- 서로의 말할 시간을 나누는 대화 시계
- 차례를 지키는 데 도움을 주는 로컬 타이머
- 누가 옳은지 판단하지 않는 기록 도구

## 향후 기능 주의
녹음, AI 요약, 클라우드 동기화가 들어가면 개인정보와 심리적 안전 리스크가 커진다. 해당 기능은 별도 문서, 명확한 동의, 삭제 기능, 정책 고지가 준비된 뒤에만 검토한다.
