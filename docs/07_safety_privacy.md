# 07. Safety, Ethics & Privacy

## 1. 핵심 원칙
말차례 CalmTurn은 민감한 대화에서 사용될 수 있으므로 안전·동의·개인정보를 제품의 중심에 둔다.

## 2. 반드시 지켜야 할 원칙
1. 양쪽 동의 없이 시작하지 않는다.
2. 한 사람이 멈추고 싶으면 멈출 수 있다.
3. 몰래 녹음하지 않는다.
4. 몰래 공유하지 않는다.
5. 앱이 누가 맞는지 판단하지 않는다.
6. 패널티를 사람의 잘못이나 관계 점수처럼 표현하지 않는다.
7. 위험하거나 폭력적인 상황에서는 사용을 중단하라고 안내한다.
8. 치료·진단·상담 효과를 보장하지 않는다.

## 3. 패널티 관련 안전 원칙
패널티는 제품적으로 유용할 수 있지만 감정 대화에서는 공격 수단이 될 수 있다. 따라서 기본 표현은 부드럽게 한다.

권장 표현:
- 오버타임 표시
- 주의 표시
- 시간 초과 기록

주의할 표현:
- 벌점
- 처벌
- 네가 잘못함
- 패배
- 감점

제품 설명:
> “오버타임 표시는 누가 잘못했는지 판단하지 않습니다. 정한 차례 시간을 넘긴 기록입니다.”

## 4. 비대칭 전체 시간의 안전 원칙
각자 다른 전체 발언 시간을 설정할 수 있지만, 한쪽이 일방적으로 불리한 규칙을 강요할 수 있다. 이를 막기 위해 다음을 적용한다.

- Consent 화면에서 각자의 전체 시간을 크게 표시한다.
- “서로 동의한 시간 배분입니다” 문구를 표시한다.
- 두 사람이 모두 동의해야 시작한다.
- 시간 연장은 기본적으로 양쪽 동의가 필요하다.

## 5. 오버타임 관련 안전 원칙
오버타임은 차례를 넘기지 않은 시간을 기록하는 기능이다. 하지만 실제 대화에서 다음 사람이 말하기 시작했는지 앱이 알 수는 없다.

MVP 원칙:
- 마이크를 사용하지 않는다.
- 음성 감지를 하지 않는다.
- 버튼 입력을 기준으로 차례를 판단한다.
- “앱 기록은 버튼 기준입니다”라고 안내한다.

## 6. 알림 관련 안전 원칙
소리와 진동은 갈등 상황에서 감정을 자극할 수 있다. 따라서 사용자가 조절할 수 있어야 한다.

- 알림 방식은 화면/소리/진동 중 선택 가능해야 한다.
- 소리 기본값은 부드럽게 하거나 꺼둘 수 있다.
- 진동을 불편해하는 사용자를 위해 끄기 옵션을 제공한다.
- 알림은 짧고 중립적이어야 한다.

## 7. MVP 개인정보 방침
### 수집하지 않는 것
- 음성 녹음
- 마이크 입력
- 위치 정보
- 연락처
- 사진
- 건강 정보
- 광고 추적 ID
- 자동 감정 분석 데이터

### 저장하는 것
- 세션 날짜
- 참가자 별칭
- 각자 설정한 전체 발언 시간
- 설정한 턴당 발언 제한
- 설정한 오버타임 기준
- 설정한 알림 방식
- 각자 사용한 시간
- 각자 오버타임 합계
- 각자 패널티 횟수
- 각자 차례 수
- 사용자가 직접 입력한 회고 메모

### 저장 위치
- 기본: 사용자 기기 내부
- 서버 전송 없음
- 클라우드 동기화 없음

## 8. 개인정보 UX
- 첫 온보딩에서 “기본적으로 기록은 이 기기에만 저장됩니다”라고 안내한다.
- 기록 삭제 버튼을 명확히 제공한다.
- 모든 기록 삭제 기능을 제공한다.
- 기록 저장 여부를 사용자가 선택할 수 있게 한다.

## 9. 온보딩 안전 문구
권장 문구:

> “말차례 CalmTurn은 대화 시간을 나누는 도구입니다. 누가 옳은지 판단하지 않으며, 관계 문제를 치료하거나 해결한다고 보장하지 않습니다.”

> “불편하거나 안전하지 않다고 느끼면 언제든 대화를 멈추세요.”

> “차례, 오버타임, 패널티는 서로 동의한 규칙을 보기 쉽게 표시하기 위한 것입니다.”

## 10. App Store 리스크 관리
피해야 할 주장:
- 부부싸움을 해결합니다.
- 관계를 치료합니다.
- 감정을 분석합니다.
- 폭력을 예방합니다.
- 상대의 잘못을 판정합니다.

권장 표현:
- 대화 시간을 나누는 타이머
- 차례를 지키는 대화 도구
- 말할 시간과 들을 시간을 정리하는 앱
- 오버타임을 기록하는 대화 시계

## 11. 향후 기능 추가 시 주의
음성 감지, 녹음, AI 요약, 클라우드 동기화가 들어가면 개인정보와 심리적 안전 리스크가 커진다. 해당 기능은 별도 동의, 명확한 개인정보 고지, 삭제 기능이 준비된 뒤에만 검토한다.
