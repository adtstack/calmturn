# 02. MVP Scope & Roadmap - v4

## MVP 원칙
v4 MVP는 “더 많은 기능”이 아니라 “갈등 상황에서 바로 쓸 수 있는 가장 단순한 2인 대화 시계”다. 시작 화면은 단순하게 유지하고, 고급 규칙은 설정 화면으로 숨긴다.

## 반드시 포함
1. 기본 이름 `남편`, `와이프`
2. 같은 총 발언시간 프리셋 `10 / 20 / 30 / 60분`
3. 턴 제한 기본값 `30초`
4. 턴 제한 프리셋 `10초 / 30초 / 45초 / 1분`
5. 첫 발언자 선택
6. 고급설정 진입 버튼
7. 유효하지 않은 시간 설정 검증
8. 좌우 2분할 실행 화면
9. 연속 시계 경계 동작
   - 경계는 50:50에서 시작한다.
   - 새 발언자의 현재 영역은 턴 시간 동안 화면 바깥쪽 끝을 향해 선형으로 줄어든다.
   - 턴이 넘어가도 경계는 현재 위치를 유지한다.
10. 전체 영역 탭으로 차례 넘기기
11. `일시정지`, `종료`만 있는 실행 화면 버튼
12. 종료 확인창
13. 마무리 화면의 총평, 해시태그, 결과 선택
14. 기록 저장과 로컬 기록 호환성
15. 기록 달력, 일자별 목록, 기록 상세

## 제외
- 시작 전 별도 동의 화면
- 실행 화면의 패널티/주의 표시
- 기본 기록 화면의 패널티/주의 표시
- 녹음, 마이크, 음성 감지
- AI 요약, 감정 분석
- 클라우드 동기화, 계정
- 상담/치료/관계 진단 문구

## 현재 단계
현재 브랜치는 v4 UI 단순화, 2분할 시계, 마무리 기록, 기록 달력, 출시 정체성 검증이 함께 올라온 내부 테스트 후보 단계다. 다음 작업은 기능 확장이 아니라 문서 정합성, 죽은 코드 제거, 검증, 실제 기기 QA다.
