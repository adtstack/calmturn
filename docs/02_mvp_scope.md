# 02. MVP Scope & Roadmap

## MVP 원칙
첫 버전은 “앱 하나로 관계 문제를 해결한다”가 아니라 “합의된 전체 발언 시간, 턴 제한, 오버타임, 패널티, 알림이 실제 대화 질서를 만드는지 검증한다”에 집중한다.

MVP의 기본 모드는 다음이다.

> **2인 대화 · 전체 발언 시간 설정 가능 · 턴당 제한 · 오버타임 측정 · 패널티 기준 1분 · 10초 전 알림**

## v3에서 MVP에 반드시 들어갈 것
1. 두 명 이름 입력
2. 전체 발언 시간 설정
   - 같은 시간
   - 각자 다른 시간
3. 턴당 발언 제한 설정
4. 첫 발언자 선택
5. 오버타임 사용 여부 설정
6. 오버타임 표시
7. 패널티 기준 시간 설정
8. 기본 패널티 기준: 오버타임 1분
9. 10초 전 알림 설정
10. 알림 방식 설정
    - 화면 표시
    - 소리
    - 진동/햅틱
11. 양쪽 동의 후 시작
12. 발언자별 전체 시간 카운트다운
13. 현재 턴 카운트다운
14. 턴 종료 후 오버타임 카운트업
15. 오버타임 기준 도달 시 패널티 기록
16. 차례 넘기기
17. 일시정지/휴식
18. 종료 후 간단한 메모
19. 로컬 기록 저장
20. 기록 삭제

## MVP에서 제외할 기능
- 로그인
- 클라우드 동기화
- 음성 녹음
- 자동 음성 인식
- 누가 말하는지 자동 감지
- AI 감정 분석
- 공개 커뮤니티
- 상담사 연결
- 결제
- 3인 이상 모드
- 라운드 모드
- 자유 차례 모드
- 푸시 알림
- 복잡한 통계 대시보드

## 중요한 해석: “다음 사람이 말할 때 누르지 않으면”
사용자 의도는 체스 시계처럼 **말을 마친 사람이 차례를 넘겨야 한다**는 것이다. 누르지 않으면 앱은 계속 이전 사람의 시간 또는 오버타임으로 기록한다.

MVP에서는 마이크로 “실제로 다음 사람이 말하기 시작했는지”를 감지하지 않는다. 따라서 앱의 기준은 다음과 같다.

- 현재 발언자 카드가 활성화되어 있다.
- 현재 발언자가 턴 시간을 모두 쓰면 오버타임이 시작된다.
- 누군가 “차례 넘기기”를 누를 때까지 오버타임은 현재 발언자에게 기록된다.
- 다음 사람이 실제로 말하기 시작했더라도 버튼을 누르지 않았다면 앱 기록상 이전 발언자의 오버타임이다.

이 규칙은 단순하고 구현 가능하며, 체스 시계의 사용 방식과도 맞다.

## v0.1 — 타이머 엔진 검증
목표: UI보다 로직을 먼저 완성한다.

포함:
- 참가자 2명 모델
- 참가자별 전체 발언 시간
- 턴당 제한
- 현재 발언자
- 차례 넘기기
- 턴 시간 종료 후 오버타임 증가
- 패널티 기준 도달 시 패널티 이벤트 생성
- 10초 전 알림 이벤트 생성
- 휴식/재개
- 종료
- 단위 테스트

완료 기준:
- 60초 턴 제한에서 61초가 지나면 오버타임 1초가 된다.
- 오버타임 60초에 도달하면 패널티가 1회 발생한다.
- 같은 턴에서 기본값으로는 패널티가 중복 발생하지 않는다.
- 차례 넘기기를 누르면 상대의 턴 시간이 새로 시작된다.
- 각자의 전체 시간이 다르게 설정되어도 정상 계산된다.
- 10초 전 알림 이벤트가 한 번만 발생한다.

## v0.2 — 세션 설정 화면
목표: 사용자가 시간 규칙을 직접 설정할 수 있다.

포함:
- 참가자 이름 입력
- 전체 발언 시간 프리셋
- 각자 다른 시간 직접 입력
- 턴당 제한 프리셋
- 오버타임 설정
- 패널티 기준 설정
- 알림 설정
- 첫 발언자 선택
- 규칙 확인 화면

완료 기준:
- A 3분, B 7분처럼 비대칭 설정이 가능하다.
- 오버타임 기준을 30초, 1분, 2분 등으로 바꿀 수 있다.
- 알림을 화면만, 소리만, 진동만, 조합으로 설정할 수 있다.
- Consent 화면에서 모든 규칙이 요약되어 보인다.

## v0.3 — 타이머 화면
목표: 실제 대화에서 쓰기 쉬운 타이머 UI를 만든다.

포함:
- 활성 발언자 강조
- 전체 남은 시간 표시
- 현재 턴 남은 시간 표시
- 오버타임 표시
- 패널티 표시
- 차례 넘기기 버튼
- 휴식 버튼
- 종료 버튼
- 10초 전 시각 알림
- 소리/진동/햅틱 피드백 연결

완료 기준:
- 멀리서도 누가 말할 차례인지 알 수 있다.
- 오버타임 상태가 명확하지만 공격적으로 보이지 않는다.
- 차례 넘기기 버튼이 손쉽게 눌린다.
- 소리/진동이 설정값을 따른다.

## v0.4 — Wrap-up & History
목표: 대화를 마친 뒤 기록을 확인하고 저장할 수 있다.

포함:
- 종료 사유
- 각자 사용한 시간
- 각자 남은 시간
- 각자 오버타임 합계
- 각자 패널티 횟수
- 휴식 횟수
- 합의한 것
- 다음에 이야기할 것
- 로컬 저장
- 기록 삭제

완료 기준:
- 승패가 아니라 “대화 기록”으로 보인다.
- 패널티가 비난처럼 보이지 않는다.
- 사용자가 기록을 삭제할 수 있다.

## v0.5 — Android 내부 테스트 준비
목표: 실제 Android 기기에서 테스트 가능한 앱으로 만든다.

포함:
- Android 앱 아이콘
- Launch screen
- 접근성 라벨
- 실제 기기에서 타이머 정확도 확인
- 실제 기기에서 진동/햅틱 확인
- 소리 설정 확인
- Android 내부 테스트 또는 APK/AAB 배포 준비

완료 기준:
- 실제 Android 기기에서 타이머가 정확히 동작한다.
- 백그라운드 복귀 후 시간이 크게 어긋나지 않는다.
- 알림이 설정값대로 동작한다.
- 민감한 개인정보를 외부로 전송하지 않는다.

## MVP 성공 판단 질문
- 사용자가 “차례 넘기기”를 자연스럽게 누르는가?
- 오버타임 표시가 싸움을 키우지 않는가?
- 패널티 기준 1분이 적절한가?
- 10초 전 알림이 실제로 도움이 되는가?
- 소리와 진동 중 무엇을 더 선호하는가?
- 각자 다른 전체 시간을 설정하는 기능이 필요한가?
- Wrap-up에서 오버타임/패널티를 보는 것이 도움이 되는가?
