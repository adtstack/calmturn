# 01. PRD — 말차례 / CalmTurn

## 1. 문서 목적
이 문서는 말차례 앱의 첫 번째 출시 버전, 즉 MVP와 v1.0의 제품 요구사항을 정의한다. 개발자는 이 문서를 기준으로 기능 범위를 고정하고, 디자이너는 사용자 흐름과 화면 우선순위를 이해하며, 창업자는 제품의 철학과 출시 전략을 공유할 수 있다.

## 2. 배경
부부, 연인, 가족, 동료 사이의 갈등 대화는 종종 내용보다 대화 방식 때문에 악화된다. 한쪽이 오래 말하거나, 말이 계속 끊기거나, 감정이 올라왔는데도 멈추지 못하면 대화는 해결이 아니라 소모가 된다.

체스 시계는 양쪽의 시간을 공평하게 배분한다. 이 구조를 대화에 적용하면 누가 옳은지를 판정하지 않고도 “서로에게 말할 기회가 있다”는 기본 질서를 만들 수 있다.

## 3. 문제 정의
### 사용자 문제
- “내가 말할 시간이 없다.”
- “상대가 계속 말을 끊는다.”
- “언제 멈춰야 할지 모르겠다.”
- “결론 없이 같은 얘기를 반복한다.”
- “대화를 시작하면 너무 길어진다.”

### 기존 대안의 한계
- 일반 타이머: 한 사람씩 명확히 전환하기 어렵다.
- 메모 앱: 대화 진행을 통제하지 못한다.
- 상담/코칭 앱: 부담이 크고 일상 대화에 쓰기 어렵다.
- 회의 타이머: 감정 대화에 필요한 휴식·동의·안전 장치가 부족하다.

## 4. 제품 목표
### MVP 목표
1. 두 사람이 같은 화면에서 공평하게 말할 시간을 나눌 수 있다.
2. 대화 중 차례 전환, 일시정지, 종료가 직관적이다.
3. 대화 후 합의 사항과 다음 대화 주제를 짧게 남길 수 있다.
4. 민감한 대화 데이터는 기본적으로 기기 안에만 저장한다.

### v1.0 목표
1. 부부/연인/회의/토론 등 상황별 프리셋을 제공한다.
2. 사용자가 직접 대화 규칙을 커스터마이즈할 수 있다.
3. TestFlight 사용자 피드백을 반영해 iOS App Store에 출시한다.
4. 안전하고 부담 없는 브랜딩으로 “싸움 앱”이 아니라 “대화 도구”로 인식된다.

## 5. 비목표
- 누가 맞는지 판정하지 않는다.
- 감정 상태를 진단하지 않는다.
- 심리 치료를 제공한다고 주장하지 않는다.
- 몰래 녹음하거나 몰래 분석하지 않는다.
- 상대를 압박하거나 감시하는 기능을 만들지 않는다.
- 첫 버전에서 온라인 커뮤니티, 랜덤 매칭, 공개 공유 기능을 만들지 않는다.

## 6. 사용자 페르소나
### Persona A: 반복적으로 말이 겹치는 부부
- 목표: 싸움이 길어지지 않게 하고 싶다.
- 두려움: 앱이 상대를 통제하는 도구처럼 보일까 걱정된다.
- 필요한 기능: 동의 기반 시작, 휴식 버튼, 간단한 합의 기록.

### Persona B: 감정 대화가 어려운 연인
- 목표: 서로 말할 시간을 보장하고 싶다.
- 두려움: 너무 기계적이면 차갑게 느껴진다.
- 필요한 기능: 따뜻한 문구, 부드러운 알림, “잠깐 쉬기”.

### Persona C: 창업자/동업자
- 목표: 민감한 이슈를 시간 안에 논의하고 결론을 내고 싶다.
- 두려움: 대화가 감정적으로 번져 업무 시간이 낭비된다.
- 필요한 기능: 의제, 시간 프리셋, 결정/액션아이템 기록.

### Persona D: 토론/스터디 진행자
- 목표: 양쪽 발언 시간을 균형 있게 관리하고 싶다.
- 두려움: 앱 조작이 복잡하면 진행을 방해한다.
- 필요한 기능: 큰 버튼, 명확한 시간 표시, 라운드 모드.

## 7. 핵심 사용자 스토리
1. 사용자는 30초 안에 새 대화 세션을 시작할 수 있다.
2. 사용자는 두 사람의 이름 또는 별칭을 입력할 수 있다.
3. 사용자는 총 시간과 1회 발언 시간을 설정할 수 있다.
4. 두 사람은 시작 전에 “동의”를 눌러 세션을 시작할 수 있다.
5. 말하는 사람의 시간이 줄어들고, 차례를 넘기면 상대 시간이 줄어든다.
6. 누구든지 휴식 버튼을 눌러 타이머를 멈출 수 있다.
7. 시간이 끝나면 앱은 대화를 마무리하도록 안내한다.
8. 세션 종료 후 사용자는 합의 사항, 미해결 이슈, 다음 대화 시간을 기록할 수 있다.
9. 사용자는 과거 세션의 시간 균형과 메모를 볼 수 있다.
10. 사용자는 언제든 세션 기록을 삭제할 수 있다.

## 8. 기능 요구사항
### F1. 새 세션 만들기
- 대화 유형 선택: 부부/연인, 가족, 회의, 토론, 직접 설정
- 참가자 2명 이름 입력
- 시간 프리셋: 3분씩, 5분씩, 10분씩, 15분씩
- 발언 방식: 총량 모드, 라운드 모드

### F2. 동의 기반 시작
- 시작 전 양쪽에 “대화 규칙에 동의합니다” 버튼 표시
- 두 버튼이 모두 눌려야 세션 시작
- 규칙 예시:
  - 말하는 사람의 시간이 흐릅니다.
  - 말이 끝나면 차례 넘기기를 누릅니다.
  - 누구든 휴식을 요청할 수 있습니다.
  - 이 앱은 승패를 정하지 않습니다.

### F3. 대화 타이머
- 화면을 위/아래 또는 좌/우로 나누어 각자의 시간 표시
- 현재 말하는 사람을 강조
- 차례 넘기기 버튼
- 일시정지 버튼
- 종료 버튼
- 남은 시간이 10초 이하일 때 부드러운 알림

### F4. 휴식 모드
- 누르면 모든 타이머 정지
- 화면 문구: “잠깐 쉬어도 괜찮아요.”
- 재개는 한 명 또는 양쪽 동의 중 선택 가능
- 기본값: 양쪽 동의 후 재개

### F5. 세션 종료
- 종료 사유 선택: 시간 종료, 합의 도달, 휴식 필요, 다음에 계속
- 짧은 회고:
  - 오늘 합의한 것
  - 아직 남은 것
  - 다음에 이야기할 것
- 감정 점수는 MVP에서 제외하거나 선택형으로만 제공

### F6. 기록 보기
- 세션 날짜, 총 시간, 참가자별 사용 시간, 메모 표시
- 삭제 기능
- 검색은 v1.1 이후

### F7. 프리셋
- “짧은 대화”: 각 3분
- “차분한 대화”: 각 10분
- “회의 정리”: 각 5분 + 합의 기록 강조
- “토론”: 라운드별 2분

## 9. 비기능 요구사항
### 성능
- 앱 실행 후 2초 안에 홈 화면 표시
- 타이머 오차는 1분 기준 ±100ms 이내를 목표로 함
- 세션 중 화면 전환 없이 주요 조작 가능

### 안정성
- 앱이 백그라운드로 가도 시간 상태가 복원되어야 함
- 세션 중 예기치 않은 종료 후 재실행 시 마지막 상태 복구
- 타이머 엔진은 단위 테스트 필수

### 개인정보
- MVP는 로컬 저장 우선
- 오디오 녹음 없음
- 클라우드 동기화 없음
- 분석 도구는 출시 전까지 끄거나 최소화
- 사용자가 기록을 삭제할 수 있어야 함

### 접근성
- 큰 글씨 지원
- VoiceOver 대응
- 색상만으로 상태를 전달하지 않음
- 버튼 터치 영역 충분히 크게 유지

## 10. 성공 지표
### MVP 검증 지표
- 첫 세션 시작까지 걸린 시간
- 세션 완료율
- 휴식 버튼 사용률
- 세션 후 “공평하다고 느꼈나요?” 응답 평균
- 다시 사용한 사용자 비율

### 정성 지표
- “대화가 덜 격해졌다”는 사용자 후기
- “상대가 말을 덜 끊었다”는 후기
- “너무 기계적이다”는 불만의 빈도
- “감시받는 느낌”이라는 불만의 빈도

## 11. 리스크와 대응
### 리스크 1: 앱이 통제 도구처럼 느껴짐
- 대응: 동의 기반 시작, 중단권, 따뜻한 카피, 승패 요소 제거

### 리스크 2: 실제 위험 상황에서 사용됨
- 대응: 앱은 위험하거나 폭력적인 상황용이 아님을 안내, 즉시 중단 문구 제공

### 리스크 3: 개인정보 우려
- 대응: 기본 로컬 저장, 녹음 없음, 공유 없음, 기록 삭제 기능 제공

### 리스크 4: App Store 심사에서 의료/상담 앱처럼 보임
- 대응: 치료·진단·관계 개선 보장 문구를 피하고 “대화 타이머/진행 도구”로 설명
