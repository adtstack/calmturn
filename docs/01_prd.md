# 01. PRD — 말차례 CalmTurn v3

## 1. 문서 목적
이 문서는 말차례 CalmTurn 앱의 첫 번째 출시 버전, 즉 MVP와 v1.0의 제품 요구사항을 정의한다. v3에서는 기존의 “전체 발언 시간 + 턴당 제한” 모델에 다음 요구사항을 추가한다.

- 각자의 전체 발언 시간을 동일하게도, 다르게도 설정할 수 있다.
- 턴 제한 시간이 끝나면 기본적으로 자동 전환하지 않고 오버타임을 측정한다.
- 오버타임이 설정된 기준 이상이면 패널티를 기록한다.
- 발언 시간이 10초 남았을 때 소리/진동/화면 알림을 줄 수 있다.
- 오버타임, 패널티 기준, 알림 시점, 알림 방식을 설정할 수 있다.

## 2. 배경
부부, 연인, 가족, 동료 사이의 갈등 대화는 종종 내용보다 대화 방식 때문에 악화된다. 한쪽이 오래 말하거나, 말이 계속 끊기거나, 감정이 올라왔는데도 멈추지 못하면 대화는 해결이 아니라 소모가 된다.

체스 시계는 양쪽의 시간을 나누지만, 대화에는 체스와 다른 특성이 있다. 대화에서는 “내 턴이 끝났는데도 계속 말하는 상황”, “상대가 이미 말하기 시작했는데 내가 차례 넘기기를 누르지 않은 상황”, “같은 시간 배분이 항상 적절하지 않은 상황”이 발생한다. 따라서 말차례 CalmTurn은 단순한 체스 시계가 아니라 **합의된 전체 발언 시간, 턴 제한, 오버타임, 패널티, 알림**을 함께 제공하는 대화 시계여야 한다.

## 3. 문제 정의
### 사용자 문제
- “내가 말할 시간이 없다.”
- “상대가 계속 말을 끊는다.”
- “상대가 한 번 말하기 시작하면 너무 오래 말한다.”
- “차례를 넘겨야 하는데 누가 눌러야 할지 애매하다.”
- “시간이 끝났는지 몰라서 계속 말하게 된다.”
- “같은 시간 배분이 항상 공평하지는 않다.”
- “상대가 시간을 넘겼다는 걸 말로 지적하면 싸움이 커진다.”
- “결론 없이 같은 얘기를 반복한다.”

### 기존 대안의 한계
- 일반 타이머: 한 사람씩 명확히 전환하기 어렵다.
- 체스 시계 앱: 대화에 필요한 턴 제한, 오버타임, 휴식, 동의 문구가 부족하다.
- 메모 앱: 대화 진행을 통제하지 못한다.
- 상담/코칭 앱: 부담이 크고 일상 대화에 쓰기 어렵다.
- 회의 타이머: 감정 대화에 필요한 휴식·동의·안전 장치가 부족하다.

## 4. 제품 목표
### MVP 목표
1. 두 사람이 같은 화면에서 각자의 전체 발언 시간을 설정할 수 있다.
2. 기본값은 동일 시간으로 제공하되, 각자 다른 전체 시간을 설정할 수 있다.
3. 한 번의 차례에 턴당 발언 제한을 적용할 수 있다.
4. 턴 제한이 끝났을 때 오버타임을 측정할 수 있다.
5. 오버타임이 설정된 기준 이상이면 패널티를 기록할 수 있다.
6. 사용자가 오버타임 기준과 패널티 기준을 바꿀 수 있다.
7. 발언 시간이 10초 남았을 때 알림을 받을 수 있다.
8. 알림 방식은 화면, 소리, 진동/햅틱 중 선택할 수 있다.
9. 대화 중 차례 전환, 휴식, 종료가 직관적이다.
10. 대화 후 합의 사항, 다음 대화 주제, 시간 사용 요약을 확인할 수 있다.
11. 민감한 대화 데이터는 기본적으로 기기 안에만 저장한다.

### v1.0 목표
1. 부부/연인/회의/토론 등 상황별 프리셋을 제공한다.
2. 사용자별 전체 발언 시간, 턴당 제한, 오버타임, 패널티, 알림을 커스터마이즈할 수 있다.
3. Android 내부 테스트 사용자 피드백을 반영해 Google Play 출시를 준비한다.
4. 안전하고 부담 없는 브랜딩으로 “싸움 앱”이 아니라 “대화 도구”로 인식된다.
5. 사용자가 패널티를 비난이 아니라 차례 관리 신호로 받아들이게 만든다.

## 5. 비목표
MVP에서는 다음을 하지 않는다.

- 음성 녹음
- 자동 음성 인식
- 누가 말하는지 자동 판별
- AI 감정 분석
- 관계 진단
- 상담 또는 치료 효과 주장
- 클라우드 동기화
- 로그인
- 공개 공유
- 온라인 커뮤니티
- 결제
- 3인 이상 모드
- 상대방 몰래 기록

중요: “다음 사람이 말하기 시작했는지”를 앱이 자동으로 감지하려면 마이크와 음성 인식이 필요하다. MVP에서는 이를 하지 않는다. 앱은 **버튼 입력과 타이머 상태**를 기준으로 오버타임을 측정한다.

## 6. 타깃 사용자
### 1차 페르소나: 부부/연인
- 반복되는 주제로 대화가 길어진다.
- 한쪽은 “내가 말할 시간이 없다”고 느낀다.
- 다른 한쪽은 “나는 설명해야 해서 길게 말한다”고 느낀다.
- 차례, 알림, 오버타임 표시가 있으면 덜 감정적으로 조율할 수 있다.

### 2차 페르소나: 팀/회의
- 발언 시간이 한 사람에게 쏠린다.
- 발표자와 피드백 제공자의 시간이 다르게 필요하다.
- 정해진 턴 시간을 넘으면 회의가 길어진다.

### 3차 페르소나: 토론/스터디
- 각자의 전체 시간과 턴 시간을 훈련하고 싶다.
- 오버타임과 패널티를 통해 규칙 준수 여부를 확인하고 싶다.

## 7. 핵심 제품 원칙
1. 앱은 판사가 아니라 진행자다.
2. 공평함은 “무조건 같은 시간”이 아니라 “동의한 시간 배분의 투명성”이다.
3. 패널티는 사람을 벌주는 점수가 아니라 규칙 초과를 표시하는 기록이다.
4. 사용자는 언제든 휴식하거나 종료할 수 있어야 한다.
5. 알림은 놀라게 하거나 공격적으로 들리면 안 된다.
6. 민감한 대화는 기본적으로 로컬에만 저장한다.

## 8. 기능 요구사항

### F-01. 새 세션 생성
사용자는 새 대화를 만들 수 있다.

필드:
- 대화 유형: 부부/연인, 가족, 회의, 토론, 직접 설정
- 참가자 A 이름
- 참가자 B 이름
- 전체 발언 시간 모드
  - 같은 시간
  - 각자 다르게
- 참가자 A 전체 발언 시간
- 참가자 B 전체 발언 시간
- 턴당 발언 제한
- 첫 발언자
- 오버타임 설정
- 패널티 설정
- 알림 설정

수용 기준:
- 이름이 비어 있으면 기본값 “나”, “상대”를 제안한다.
- 전체 발언 시간은 0보다 커야 한다.
- 턴당 발언 제한은 0보다 커야 한다.
- 각자 다른 전체 시간이더라도 Consent 화면에서 명확히 보여준다.

### F-02. 전체 발언 시간 설정
사용자는 각자의 전체 발언 시간을 설정할 수 있다.

기본 프리셋:
- 각자 3분
- 각자 5분
- 각자 10분
- 각자 15분
- 직접 설정

직접 설정:
- 같은 시간 입력
- 참가자별 개별 입력

수용 기준:
- 기본값은 각자 5분이다.
- 각자 다른 시간을 설정하면 “서로 동의한 시간 배분입니다”라는 문구를 표시한다.
- 진행 중 한 사람의 전체 시간이 0이 되면 자동으로 휴식/종료 선택 상태로 전환한다.
- 전체 시간이 0인 상태에서는 추가 시간 동의 없이 계속 진행하지 않는다.

### F-03. 턴당 발언 제한
사용자는 한 번의 차례에서 말할 수 있는 기본 제한 시간을 설정할 수 있다.

기본 프리셋:
- 30초
- 45초
- 1분
- 1분 30초
- 2분
- 직접 설정

수용 기준:
- 기본값은 1분이다.
- 현재 발언자의 턴 시간이 줄어든다.
- 현재 턴 남은 시간이 0이 되면 오버타임 상태로 들어간다.
- 말이 일찍 끝나면 “차례 넘기기”로 상대에게 넘길 수 있다.

### F-04. 오버타임 측정
오버타임은 턴 시간이 0이 된 뒤 차례 넘기기를 누르지 않은 시간이다.

동작:
- 턴 시간이 0이 되면 오버타임이 0초부터 증가한다.
- 현재 발언자의 전체 남은 시간이 있다면 전체 발언 시간은 계속 줄어든다.
- 차례 넘기기를 누르면 현재 턴의 오버타임이 종료되고 상대 차례가 시작된다.
- 오버타임 시간은 세션 기록에 저장된다.

기본값:
- 오버타임 사용: 켜짐
- 오버타임 표시: 켜짐
- 오버타임 카운트 방향: 0초부터 증가

수용 기준:
- 오버타임 상태에서는 화면에 “오버타임 +00:12”처럼 표시한다.
- 오버타임이 시작될 때 부드러운 알림을 줄 수 있다.
- 오버타임 중에도 휴식/종료/차례 넘기기가 가능해야 한다.

### F-05. 패널티
패널티는 오버타임이 설정한 기준 이상이 되었을 때 발생하는 기록이다.

기본값:
- 패널티 기준: 오버타임 1분
- 패널티 반복: 기본 꺼짐
- 패널티 표시 방식: 중립적 표시
- 내부 명칭: penalty
- 사용자에게 보이는 권장 명칭: “오버타임 표시”, “주의 표시”, “패널티” 중 설정 가능

동작:
- 오버타임이 60초에 도달하면 현재 발언자에게 패널티 1회가 기록된다.
- 기본은 한 턴에 패널티 1회만 기록한다.
- 반복 패널티를 켜면 설정 기준마다 추가 패널티가 기록된다.
  - 예: 기준 60초, 반복 켜짐 → 60초, 120초, 180초마다 패널티
- 패널티는 상대방을 비난하는 문구로 표현하지 않는다.

수용 기준:
- 패널티가 발생하면 화면에 짧게 표시한다.
- 패널티 발생 시 소리/진동/화면 알림 여부는 설정을 따른다.
- Wrap-up 화면에 참가자별 패널티 횟수와 오버타임 합계를 표시한다.

### F-06. 알림
발언 시간이 얼마 남았는지 사용자에게 알려준다.

기본값:
- 사전 알림 시점: 10초 전
- 턴 시간 10초 전 알림: 켜짐
- 전체 발언 시간 10초 전 알림: 켜짐
- 오버타임 시작 알림: 켜짐
- 패널티 도달 알림: 켜짐
- 알림 방식: 화면 표시 + 진동/햅틱
- 소리: 사용자가 켤 수 있음

알림 방식:
- 화면 표시
- 소리
- 진동/햅틱
- 조합 가능
- 전체 끄기 가능

수용 기준:
- 알림은 같은 이벤트에 대해 중복 반복되지 않는다.
- 사용자가 소리를 꺼두면 소리를 내지 않는다.
- 진동/햅틱이 불가능한 기기에서는 화면 표시로 대체한다.
- 10초 전 알림 값은 5초, 10초, 15초, 30초, 직접 입력으로 바꿀 수 있다.

### F-07. 타이머 진행
기본 흐름:
1. Consent 후 세션이 시작된다.
2. 첫 발언자의 전체 시간과 턴 시간이 줄어든다.
3. 설정된 사전 알림 시점에 알림을 준다.
4. 턴 시간이 0이 되면 오버타임 상태로 진입한다.
5. 오버타임이 패널티 기준에 도달하면 패널티를 기록한다.
6. 차례 넘기기를 누르면 상대의 턴이 시작된다.
7. 누군가의 전체 시간이 0이 되면 대화를 멈추고 종료/연장 선택을 보여준다.
8. 휴식 버튼을 누르면 모든 시간이 멈춘다.

수용 기준:
- 타이머 로직은 UI와 분리한다.
- 1초 단위 테스트가 가능해야 한다.
- 앱이 백그라운드로 갔다 돌아와도 경과 시간을 계산해야 한다.

### F-08. 휴식
누구든 휴식 버튼을 누를 수 있다.

동작:
- 전체 시간, 턴 시간, 오버타임이 모두 멈춘다.
- 휴식 시간은 별도로 기록할 수 있다.
- 재개 시 같은 발언자의 같은 턴으로 돌아간다.
- 종료도 가능하다.

수용 기준:
- 휴식은 패널티가 아니다.
- 휴식 중에는 오버타임이 증가하지 않는다.

### F-09. 시간 연장
누군가의 전체 시간이 0이 되었거나 대화가 더 필요할 때 시간을 연장할 수 있다.

동작:
- 연장 시간 프리셋: 1분, 3분, 5분, 직접 설정
- 어느 참가자에게 추가할지 선택
- 기본은 양쪽 동의 필요

수용 기준:
- 한쪽만 일방적으로 시간을 늘리는 흐름을 기본으로 만들지 않는다.
- 연장 기록은 세션 기록에 남긴다.

### F-10. Wrap-up
대화가 끝나면 요약 화면을 보여준다.

표시:
- 각자 사용한 전체 시간
- 각자 남은 전체 시간
- 각자 턴 횟수
- 각자 오버타임 합계
- 각자 패널티 횟수
- 휴식 횟수
- 합의한 것
- 다음에 이야기할 것

수용 기준:
- 승자/패자 표현을 쓰지 않는다.
- “누가 잘못했다”가 아니라 “오늘의 대화 기록”으로 표현한다.

### F-11. 기록 저장
MVP는 로컬 저장만 한다.

저장 항목:
- 세션 날짜
- 참가자 별칭
- 설정한 전체 발언 시간
- 설정한 턴당 발언 제한
- 설정한 오버타임 기준
- 설정한 알림 방식
- 사용한 시간
- 오버타임 합계
- 패널티 횟수
- 휴식 횟수
- 사용자가 직접 입력한 회고 메모

수용 기준:
- 사용자가 기록을 삭제할 수 있다.
- 음성 녹음은 하지 않는다.
- 클라우드 전송은 하지 않는다.

## 11. 주요 정책 결정
### 11.1 턴 종료 시 자동 전환 여부
기본값은 자동 전환이 아니다. 턴 시간이 끝나면 오버타임으로 진입한다. 이유는 실제 대화에서 누가 차례를 넘겼는지, 누가 더 말했는지를 기록하는 것이 중요하기 때문이다.

MVP 기본은 오버타임 모드다. 사용자가 오버타임을 끄면 턴 종료 시 자동 휴식 모드로 이동한다.

선택 옵션으로는 후속 버전에서 다음을 제공할 수 있다.
- 자동 전환 모드
- 오버타임 최대 허용 시간 후 자동 휴식

### 11.2 패널티 표현
제품 내부에서는 penalty라고 부를 수 있지만, 사용자에게는 부드러운 표현을 우선한다.

권장 표현:
- 오버타임 표시
- 주의 표시
- 시간 초과 기록

상황에 따라 “패널티”라는 명칭도 설정 화면에서 사용할 수 있지만, 대화 화면에서는 공격적으로 보이지 않게 한다.

### 11.3 알림 기본값
기본값은 화면 표시 + 진동/햅틱이다. 소리는 사용자가 켤 수 있게 한다. 갈등 대화에서 날카로운 소리는 감정을 키울 수 있으므로, 소리의 기본값은 부드럽게 하거나 꺼두는 방향을 검토한다.

## 12. 리스크와 대응
| 리스크 | 설명 | 대응 |
|---|---|---|
| 패널티가 비난처럼 느껴짐 | 상대가 “너 패널티야”라고 공격할 수 있음 | 중립 카피, 기록 중심 표현, 온보딩 안내 |
| 알림이 감정을 자극함 | 소리/진동이 싸움을 키울 수 있음 | 알림 방식 설정, 소리 기본값 보수적 적용 |
| 비대칭 시간이 불공평하게 느껴짐 | 한쪽이 더 많은 시간을 받을 수 있음 | Consent에서 명확히 표시하고 양쪽 동의 필요 |
| 앱을 강요 수단으로 사용 | 한 사람이 상대에게 사용을 강제할 수 있음 | 시작 전 양쪽 동의, 중단권 안내 |
| 음성 감지 기대 | 사용자가 자동 감지를 기대할 수 있음 | MVP는 버튼 기준임을 명확히 안내 |

## 13. MVP 완료 조건
- 2인 세션을 만들 수 있다.
- 각자의 전체 발언 시간을 동일 또는 다르게 설정할 수 있다.
- 턴 제한을 설정할 수 있다.
- 턴 시간이 끝나면 오버타임이 증가한다.
- 오버타임 1분 이상이면 패널티가 기록된다.
- 패널티 기준을 바꿀 수 있다.
- 10초 전 알림이 동작한다.
- 알림 방식이 설정 가능하다.
- 휴식과 종료가 동작한다.
- Wrap-up에서 시간 사용, 오버타임, 패널티가 보인다.
- 기록이 로컬에 저장되고 삭제 가능하다.
