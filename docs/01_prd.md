# 01. PRD - v4

## 목적
이 문서는 `시계 (부부싸움 시리즈)` v4 내부 테스트 후보의 제품 요구사항을 정의한다. v4는 기능을 늘리는 버전이 아니라, 대화 시계를 가장 단순한 형태로 줄이고 기록 흐름을 마무리하는 버전이다.

## 문제
부부싸움 중에는 한 사람이 오래 말하거나 차례가 흐려지기 쉽다. 앱은 누가 옳은지 판단하지 않고, 같은 총 발언시간과 턴 제한을 눈에 보이게 만들어 대화의 질서를 돕는다.

## 목표
1. 두 사람이 같은 총 발언시간으로 시작한다.
2. 시작 화면은 핵심 설정만 보여준다.
3. 실행 화면은 2분할 시계와 큰 터치 영역으로 동작한다.
4. 종료 후 총평, 해시태그, 결과를 저장한다.
5. 기록 달력과 상세 화면에서 저장된 대화를 다시 볼 수 있다.
6. Android 내부 테스트 후보로 검증 가능한 상태를 만든다.

## 비목표
- 녹음, 마이크, 음성 감지
- 감정 분석, AI 요약
- 클라우드 동기화, 사용자 계정
- 상담, 치료, 관계 진단
- 승패 또는 잘못 판정

## 사용자
- 1차 사용자: 싸움이나 민감한 대화에서 말할 시간을 나누고 싶은 부부/연인
- 2차 사용자: 가족, 동료, 스터디처럼 2인 대화 시간을 나누고 싶은 사용자

## 기능 요구사항

### F-01. 시작/설정
- 기본 참가자 이름은 `남편`, `와이프`다.
- 사용자는 두 이름을 바꿀 수 있다.
- 사용자는 첫 발언자를 고를 수 있다.
- 각자 총 발언시간 프리셋은 `10 / 20 / 30 / 60분`이다.
- 턴 제한 기본값은 `30초`이다.
- 턴 제한 프리셋은 `10초 / 30초 / 45초 / 1분`이다.
- 유효하지 않은 설정은 시작 전에 메시지로 막는다.
- `시작`을 누르면 별도 동의 화면 없이 바로 실행 화면으로 이동한다.

### F-02. 고급설정
- 시작 화면 우상단 톱니바퀴에서 진입한다.
- 고급설정에는 세부 시간 규칙, 오버타임, 알림, 내부 패널티 기록 설정을 둔다.
- 별도 저장 버튼은 두지 않는다.
- 뒤로 가면 유효한 설정을 자동 저장한다.
- 고급설정 내용은 시작 화면을 복잡하게 만들지 않는다.

### F-03. 실행 화면
- 화면은 좌우 2분할이다.
- 왼쪽은 첫 번째 참가자, 오른쪽은 두 번째 참가자다.
- 시작 폭은 50:50이다.
- 현재 발언자의 총 남은 시간이 줄면 해당 영역 폭도 줄어든다.
- 각 영역 전체를 탭하면 차례가 넘어간다.
- 상단에는 `일시정지`와 `종료`만 표시한다.
- 종료는 확인창에서 한 번 더 묻는다.

### F-04. 오버타임과 내부 패널티 기록
- 턴 제한을 넘기면 오버타임 상태로 들어갈 수 있다.
- 오버타임은 설정에 따라 보이거나 숨겨질 수 있다.
- 패널티/주의 표시는 실행 화면과 기본 기록 화면에 노출하지 않는다.
- 내부 데이터에는 기존 패널티 카운트를 유지해 호환성을 보존한다.
- 앱은 누가 잘못했는지 판단하지 않는다.

### F-05. 마무리
- 종료 후 대화 시간 요약을 보여준다.
- 사용자는 총평을 입력할 수 있다.
- 사용자는 해시태그를 입력할 수 있다.
- 사용자는 결과를 `잘 마무리됨` 또는 `아직 남음`으로 고른다.
- 저장하지 않고 마칠 수 있다.
- 저장 후 기록 화면으로 이동할 수 있다.

### F-06. 기록
- 새 기록 필드는 `summaryText`, `tagsText`, `outcome`이다.
- `outcome` 값은 `resolved`, `unresolved`이다.
- 달력 표시는 `resolved`를 `O`, `unresolved`를 `X`로 보여준다.
- 날짜 아래에는 최대 3개 결과만 표시한다.
- 일자별 기록은 3-4개 정도를 자연스럽게 볼 수 있는 목록이어야 한다.
- 상세 화면은 시간, 총평, 해시태그, O/X, 참가자별 사용 시간을 보여준다.
- 기존 로컬 기록은 새 필드가 없어도 읽을 수 있어야 한다.
