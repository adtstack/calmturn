# 12. Settings & Notifications - v4

## 목적
이 문서는 v4의 설정값과 알림 정책을 정리한다. 시작 화면은 단순하게 유지하고, 세부 설정은 고급설정 화면에서 다룬다.

## 시작 화면 설정
| 설정 | 기본값 | 시작 화면 표시 |
|---|---:|---|
| 참가자 A 이름 | 남편 | 예 |
| 참가자 B 이름 | 와이프 | 예 |
| 각자 총 발언시간 | 10분 | 예 |
| 턴 제한 | 3분 | 예 |
| 첫 발언자 | 남편 | 예 |

## 고급설정
고급설정은 시작 화면 우상단 톱니바퀴에서 연다. 시작 화면은 이름, 총 발언시간, 턴 제한, 첫 발언자만 빠르게 고르게 하고, 아래 세부 규칙은 다음 대화의 기본값으로만 조정한다.

- 전체 시간 세부 규칙
- 턴 제한 세부 규칙
- 오버타임 사용 여부
- 내부 패널티 기록 기준
- 알림 대상
- 알림 방식
- 자동 저장

## 시간 범위
- 총 발언시간 직접 입력 범위: 1분부터 240분
- 턴 제한 직접 입력 범위: 1분부터 60분
- 턴 제한은 가장 짧은 총 발언시간보다 길 수 없다.

## 오버타임
| 설정 | 기본값 |
|---|---:|
| 오버타임 사용 | 켜짐 |
| 오버타임 표시 | 켜짐 |
| 오버타임 동작 | 턴 제한 이후 계속 측정 |

오버타임은 턴 제한 뒤에도 시간이 이어질 때 내부 기록과 실행 화면 타이머에 반영되는 값이다. 오버타임을 끄면 턴 시간이 끝났을 때 차례 종료 상태로 멈출 수 있다.

## 내부 패널티 기록
| 설정 | 기본값 |
|---|---:|
| 내부 기록 사용 | 켜짐 |
| 기준 | 1분 |
| 반복 | 한 턴에 1회 |

이 값은 기존 기록과 알림 이벤트 호환성을 위한 내부 데이터다. 사용자-facing 실행 화면과 기본 기록 화면에는 패널티/주의 표시를 노출하지 않고, 고급설정에서는 `내부 기록 기준`과 `내부 기준 도달`로 설명한다.

## 알림 대상
- 턴 시간 종료 전
- 전체 발언시간 종료 전
- 오버타임 시작
- 내부 기준 도달

## 알림 방식
- 화면
- 소리
- 진동

기본은 화면과 진동이다. 알림 대상이 하나 이상 켜져 있으면 알림 방식도 하나 이상 켜져 있어야 한다. 알림 방식이 하나 이상 켜져 있으면 알림 대상도 하나 이상 켜져 있어야 한다. 내부 기준 도달 알림은 호환성용 이벤트이며 패널티/주의 문구를 실행 화면에 직접 노출하지 않는다.

## 자동 저장
- 세션 설정은 시작할 때 저장한다.
- 고급설정은 뒤로 갈 때 유효한 설정만 저장한다.
- 기록 자동 저장은 고급설정에서 조정한다.
- 사용자가 마무리 화면에서 직접 기록 저장을 누를 수 있다.

## 테스트 체크리스트
- [x] 시작 화면에 오버타임/패널티 세부 설정이 직접 보이지 않는다.
- [x] 고급설정에서 오버타임 설정을 바꿀 수 있다.
- [x] 유효하지 않은 시간 규칙은 저장 또는 시작 전에 막힌다.
- [x] 알림 대상과 방식이 서로 비어 있지 않도록 검증한다.
- [x] 패널티/주의 문구가 실행 화면과 기본 기록 화면에 노출되지 않는다.
