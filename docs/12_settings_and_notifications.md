# 12. Settings & Notifications - v4

## 목적
이 문서는 v4의 설정값과 알림 정책을 정리한다. 시작 화면은 단순하게 유지하고, 세부 설정은 고급설정 화면에서 다룬다.

## 시작 화면 설정
| 설정 | 기본값 | 시작 화면 표시 |
|---|---:|---|
| 참가자 A 이름 | 남편 | 예 |
| 참가자 B 이름 | 와이프 | 예 |
| 각자 총 발언시간 | 10분 | 예 |
| 턴 제한 | 3분 | 예 |
| 첫 발언자 | 남편 | 예 |

## 고급설정
고급설정은 시작 화면 우상단 톱니바퀴에서 연다.

- 전체 시간 세부 규칙
- 턴 제한 세부 규칙
- 오버타임 사용 여부
- 오버타임 표시 여부
- 내부 패널티 기록 기준
- 알림 대상
- 알림 방식
- 자동 저장

## 시간 범위
- 총 발언시간 직접 입력 범위: 1분부터 240분
- 턴 제한 직접 입력 범위: 1분부터 60분
- 턴 제한은 가장 짧은 총 발언시간보다 길 수 없다.

## 오버타임
| 설정 | 기본값 |
|---|---:|
| 오버타임 사용 | 켜짐 |
| 오버타임 표시 | 켜짐 |
| 오버타임 동작 | 턴 제한 이후 계속 측정 |

오버타임을 끄면 턴 시간이 끝난 뒤 자동 휴식 상태로 이동할 수 있다.

## 내부 패널티 기록
| 설정 | 기본값 |
|---|---:|
| 내부 기록 사용 | 켜짐 |
| 기준 | 1분 |
| 반복 | 한 턴에 1회 |

이 값은 기존 기록과 알림 이벤트 호환성을 위한 내부 데이터다. 실행 화면과 기본 기록 화면에는 패널티/주의 표시를 노출하지 않는다.

## 알림 대상
- 턴 시간 종료 전
- 전체 발언시간 종료 전
- 오버타임 시작
- 내부 기준 도달

## 알림 방식
- 화면
- 소리
- 진동

기본은 화면과 진동이다. 알림 대상이 하나 이상 켜져 있으면 알림 방식도 하나 이상 켜져 있어야 한다. 알림 방식이 하나 이상 켜져 있으면 알림 대상도 하나 이상 켜져 있어야 한다.

## 자동 저장
- 세션 설정은 시작할 때 저장한다.
- 고급설정은 뒤로 갈 때 유효한 설정만 저장한다.
- 기록 자동 저장은 고급설정에서 조정한다.
- 사용자가 마무리 화면에서 직접 기록 저장을 누를 수 있다.

## 테스트 체크리스트
- [ ] 시작 화면에 오버타임/패널티 세부 설정이 직접 보이지 않는다.
- [ ] 고급설정에서 오버타임 설정을 바꿀 수 있다.
- [ ] 유효하지 않은 시간 규칙은 저장 또는 시작 전에 막힌다.
- [ ] 알림 대상과 방식이 서로 비어 있지 않도록 검증한다.
- [ ] 패널티/주의 문구가 실행 화면과 기본 기록 화면에 노출되지 않는다.
