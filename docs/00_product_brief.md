# 00. Product Brief - v4

## 제품 가설
갈등 상황에서는 말의 내용보다 “내가 말할 시간이 부족하다” 또는 “상대가 너무 오래 말한다”는 감각이 먼저 커진다. `시계 (부부싸움 시리즈)`는 대화의 옳고 그름을 판단하지 않고, 두 사람이 같은 총 발언시간 안에서 차례를 지키도록 돕는다.

## 한 문장
`시계 (부부싸움 시리즈)`는 부부싸움 중 두 사람이 같은 총 발언시간을 갖고, 정해진 턴 제한 안에서 번갈아 말하도록 돕는 가장 단순한 대화 시계다.

## 이름
- 앱 표시명: `시계 (부부싸움 시리즈)`
- 짧은 표시명: `시계`
- 내부 프로젝트/패키지 맥락: CalmTurn, `me.newlines.calmturn`

## v4 제품 원칙
1. 시작 화면은 이름, 첫 발언자, 각자 총 발언시간, 턴 제한만 보여준다.
2. 공평함은 같은 총 발언시간이다.
3. 고급설정은 시작 화면 우상단 톱니바퀴 뒤로 숨긴다.
4. 패널티/주의 표시는 사용자-facing 화면에 노출하지 않는다.
5. 기록은 판단이 아니라 회고를 돕는 로컬 데이터다.

## 핵심 경험
1. 사용자는 기본값 또는 마지막 저장 설정을 확인한다.
2. 두 사람의 이름, 첫 발언자, 총 발언시간, 턴 제한을 고른다.
3. `시작`을 누르면 동의 확인 화면 없이 바로 시계가 시작된다.
4. 실행 화면은 가로 2분할이며, 각 영역 전체가 차례 넘기기 터치 영역이다.
5. 경계는 50:50에서 시작한다.
6. 새 발언자의 현재 영역은 턴 시간 동안 화면 바깥쪽 끝을 향해 선형으로 줄어든다.
7. 턴이 넘어가도 경계는 현재 위치를 유지한다.
8. 종료 시 확인창을 거쳐 마무리 화면으로 이동한다.
9. 총평, 해시태그, 결과(`잘 마무리됨` / `아직 남음`)를 저장한다.
10. 기록 달력은 날짜별 O/X를 최대 3개까지 보여준다.

## 비목표
- 녹음, 마이크 입력, 음성 감지
- 감정 분석, AI 요약, 상담/치료 기능
- 클라우드 동기화, 계정, 서버 전송
- 승패, 잘못, 책임을 판정하는 기능

## 성공 기준
- 첫 화면에서 기능을 설명하지 않아도 시작할 수 있다.
- 실행 중 필요한 버튼은 `일시정지`와 `종료`뿐이다.
- 패널티/주의 표현 없이도 오버타임과 내부 기록이 유지된다.
- 종료 후 기록이 달력, 일자별 목록, 상세 화면까지 자연스럽게 이어진다.
- README의 출시 전 검증 명령이 모두 통과한다.
