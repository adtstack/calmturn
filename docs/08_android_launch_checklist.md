# 08. Android / Google Play Launch Checklist - v4

## 1. 앱 정체성
- 앱 표시명: `시계 (부부싸움 시리즈)`
- 짧은 이름: `시계`
- 패키지명: `me.newlines.calmturn`
- 아이콘: turn ring concept
- 현재 버전: `pubspec.yaml` 기준
  - 현재값: `0.1.0+1`.

## 2. 버전 규칙
- `versionName`은 `pubspec.yaml`의 `version`에서 `+` 앞의 SemVer(`0.1.0`)를 사용한다.
- `versionCode`는 `pubspec.yaml`의 `version`에서 `+` 뒤의 빌드 번호(`1`)를 사용한다.
- Android Gradle 설정은 Flutter의 `versionCode`와 `versionName`을 위임받는다.
- 검증: `flutter test test/release_identity_test.dart`

## 3. 자동 검증
내부 테스트 후보는 아래 명령이 통과해야 한다.

```bash
./tool/check.sh
flutter test test/release_identity_test.dart
git diff --check
```

- [ ] `flutter doctor -v`에서 Android toolchain 문제가 없다.

## 5. v4 기능 기준 수동 테스트

### 시작/설정
- [ ] 첫 실행에서 `남편`, `와이프` 기본 이름이 보인다.
- [ ] `각자 10 / 20 / 30 / 60분` 프리셋이 보인다.
- [ ] `턴 10초 / 30초 / 45초 / 1분` 프리셋이 보인다.
- [ ] 톱니바퀴로 고급설정에 들어갈 수 있다.
- [ ] `시작`을 누르면 별도 동의 화면 없이 실행 화면으로 간다.

### 실행
- [ ] 좌우 2분할 화면이 보인다.
- [ ] 현재 발언자의 시간만 줄어든다.
- [ ] 현재 발언자의 영역 폭이 총 남은 시간에 맞춰 줄어든다.
- [ ] 영역 전체를 탭하면 차례가 넘어간다.
- [ ] `일시정지`와 `종료`만 표시된다.
- [ ] 종료는 확인창을 거친다.
- [ ] 패널티/주의 문구가 보이지 않는다.

### 마무리/기록
- [ ] 총평을 입력할 수 있다.
- [ ] 해시태그를 입력할 수 있다.
- [ ] `잘 마무리됨`과 `아직 남음`을 고를 수 있다.
- [ ] 기록 저장 후 기록 화면에서 볼 수 있다.
- [ ] 기록 달력에 O/X가 최대 3개 표시된다.
- [ ] 기록 상세에서 시간, 총평, 해시태그, 결과, 참가자별 사용 시간이 보인다.

## 8. Google Play 설명 기준
- 앱은 대화 시간을 나누는 로컬 타이머로 설명한다.
- 부부싸움을 해결하거나 치료한다고 쓰지 않는다.
- 감정 분석, 녹음, AI 요약을 암시하지 않는다.
- 앱이 누가 맞는지 판단하지 않는다고 명확히 쓴다.
