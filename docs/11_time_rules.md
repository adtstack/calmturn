# 11. Time Rules - v4

## 핵심 결론
v4의 공평함은 같은 총 발언시간이다. 두 사람은 같은 총 시간을 받고, 한 번의 차례마다 턴 제한 안에서 말한다.

## 기본값
| 항목 | 기본값 |
|---|---:|
| 참가자 A | 남편 |
| 참가자 B | 와이프 |
| 각자 총 발언시간 | 10분 |
| 턴 제한 | 30초 |
| 첫 발언자 | 남편 |
| 오버타임 | 켜짐 |
| 알림 | 화면 + 진동 |

## 전체 발언시간
- 시작 화면 프리셋은 `10 / 20 / 30 / 60분`이다.
- 시작 화면에서는 두 사람이 같은 총 발언시간을 갖는다.
- 시간은 현재 발언자에게만 흐른다.

## 시계 경계
- 경계는 50:50에서 시작한다.
- 새 발언자의 현재 영역은 턴 시간 동안 화면 바깥쪽 끝을 향해 선형으로 줄어든다.
- 턴이 넘어가도 경계는 현재 위치를 유지한다.
- 일시정지 중에는 경계 위치를 그대로 유지하고, 재개하면 그 위치에서 움직임을 이어간다.
- 오버타임 중에는 경계가 현재 발언자 쪽 화면 바깥쪽 끝에 고정된다.

## 턴 제한
- 턴 제한은 한 번의 발언 차례에 적용된다.
- 시작 화면 프리셋은 `10초 / 30초 / 45초 / 1분`이다.
- 턴 제한은 가장 짧은 총 발언시간보다 길 수 없다.
- 턴이 넘어가면 새 발언자의 턴 시간이 다시 시작된다.

## 오버타임
- 턴 시간이 0이 된 뒤에도 차례를 넘기지 않으면 오버타임 상태가 될 수 있다.
- 오버타임 중에도 현재 발언자의 총 시간은 줄어든다.
- 오버타임 표시는 설정으로 숨길 수 있다.
- 오버타임을 끄면 턴 시간이 끝났을 때 자동 휴식 상태로 들어갈 수 있다.

## 내부 패널티 기록
- 패널티는 오버타임 기준 도달을 기록하는 내부 데이터다.
- 실행 화면과 기본 기록 화면에는 패널티/주의 표시를 노출하지 않는다.
- 기존 기록 호환성을 위해 카운트는 유지한다.
- 패널티는 잘못이나 승패 판단에 사용하지 않는다.

## 알림
- 알림은 턴 종료 전, 전체 시간 종료 전, 오버타임 시작, 내부 기준 도달 이벤트에 반응할 수 있다.
- 알림 방식은 화면, 소리, 진동이다.
- 사용자-facing 문구는 판단적 표현을 피한다.

## 예시
1. 두 사람 모두 각자 10분을 받는다.
2. 턴 제한은 30초이다.
3. 남편이 먼저 말하면 경계는 중앙에서 출발한다.
4. 남편이 15초 말하면 턴 남은 시간은 15초, 총 남은 시간은 9분 45초가 된다.
5. 같은 15초 동안 남편의 현재 영역은 남편 쪽 화면 바깥쪽 끝을 향해 선형으로 절반 줄어든다.
6. 화면을 탭하면 경계 위치를 유지한 채 와이프 차례로 넘어간다.
7. 와이프 쪽 화면 바깥쪽 끝부터 유지된 경계까지가 새 턴의 이동 거리가 된다.
8. 와이프의 턴 제한이 30초로 시작되고 현재 영역이 와이프 쪽 화면 바깥쪽 끝을 향해 선형으로 줄어든다.

## 엣지 케이스
- 턴 제한이 총 발언시간보다 길면 시작할 수 없다.
- 총 시간이 0이 되면 세션은 추가 진행이 필요한 상태가 된다.
- 일시정지 중에는 시간이 흐르지 않는다.
- 기존 기록에 outcome이 없으면 달력에서는 `-`로 표시한다.
