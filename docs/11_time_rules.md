# 11. Time Rules — 전체 시간, 턴 제한, 오버타임, 패널티

## 1. 이 문서의 목적
이 문서는 말차례 CalmTurn의 가장 중요한 제품 규칙을 정리한다. 앱 개발 중 혼란이 생기면 이 문서를 우선 기준으로 삼는다.

## 2. v3 핵심 결론
말차례 CalmTurn은 단순한 체스 시계가 아니다. v3의 기본 규칙은 다음이다.

> **각 참여자는 서로 동의한 전체 발언 시간을 받고, 각 발언 차례마다 턴당 제한 안에서 말한다. 턴 제한을 넘기면 오버타임이 기록되고, 설정한 기준을 넘으면 패널티가 발생한다.**

즉, 앱에는 네 개의 시간/규칙이 있다.

| 개념 | 질문 | 기본값 | 역할 |
|---|---|---:|---|
| 전체 발언 시간 | “이 사람이 대화 전체에서 얼마나 말할 수 있나?” | 각자 5분 | 전체 발언량 관리 |
| 턴당 발언 제한 | “이번 차례에서 기본적으로 얼마나 말할 수 있나?” | 1분 | 한 번의 긴 독점 방지 |
| 오버타임 | “턴 제한이 끝난 뒤 얼마나 더 말했나?” | 켜짐 | 시간 초과 측정 |
| 패널티 기준 | “오버타임이 몇 초 이상이면 표시할까?” | 1분 | 규칙 준수 신호 |
| 사전 알림 | “몇 초 남았을 때 알려줄까?” | 10초 | 자연스러운 마무리 유도 |

## 3. 전체 발언 시간 규칙
### 3.1 기본값은 같은 시간
기본은 각자 같은 전체 발언 시간이다.

예:
```text
A = 5분
B = 5분
```

### 3.2 각자 다르게 설정 가능
사용자가 합의하면 각자 다른 전체 발언 시간을 설정할 수 있다.

예:
```text
A = 3분
B = 7분
```

### 3.3 공평함의 정의
이 앱에서 공평함은 무조건 같은 시간이 아니다.

> **공평함 = 시작 전에 서로 동의한 시간 배분이 대화 중 투명하게 보이는 것.**

### 3.4 전체 시간이 0이 되면
누군가의 전체 시간이 0이 되면 그 사람은 더 이상 말할 시간이 없다. 이때 앱은 자동으로 계속 진행하지 않는다.

선택지:
- 오늘은 여기까지
- 시간 추가
- 휴식

시간 추가는 기본적으로 양쪽 동의가 필요하다.

## 4. 턴당 발언 제한 규칙
### 4.1 턴 제한은 한 번의 차례에 적용된다
예:
```text
전체 시간: A 5분, B 5분
턴 제한: 1분
```

A는 한 번의 차례에서 기본적으로 1분까지 말한다. 말이 끝나면 차례 넘기기를 눌러 B에게 넘긴다.

### 4.2 현재 발언자의 시간만 줄어든다
A가 말하는 동안:
```text
A 전체 시간 감소
A 턴 시간 감소
B 시간 유지
```

B가 말하는 동안:
```text
B 전체 시간 감소
B 턴 시간 감소
A 시간 유지
```

### 4.3 실제 발언 가능 시간
현재 턴에서 실제로 남은 정상 발언 시간은 다음과 같다.

```text
정상 발언 가능 시간 = min(현재 발언자의 전체 남은 시간, 턴 남은 시간)
```

## 5. 오버타임 규칙
### 5.1 오버타임의 정의
오버타임은 턴 시간이 0이 된 뒤, 차례 넘기기를 누르지 않은 시간이다.

```text
턴 남은 시간 = 0
차례 넘기기 미입력
=> 오버타임 시작
```

### 5.2 자동 전환하지 않는다
MVP 기본 동작은 자동 전환이 아니다. 턴 제한이 끝나면 상대 차례로 자동 변경되지 않고, 오버타임이 시작된다.

이유:
- 실제 대화에서는 차례를 넘기는 행동 자체가 중요하다.
- 다음 사람이 말하기 시작했더라도 버튼을 누르지 않으면 앱 기록상 이전 발언자의 시간이 계속 흐른다.
- 체스 시계처럼 “내 차례를 끝내면 눌러야 한다”는 습관을 만든다.

### 5.3 오버타임 중 전체 시간
오버타임 중에도 현재 발언자의 전체 시간이 남아 있다면 전체 시간은 계속 줄어든다.

```text
오버타임 중:
currentTurnOvertimeSeconds 증가
active.totalRemainingSeconds 감소
```

### 5.4 오버타임 중 전체 시간이 0이 되면
전체 시간이 0이 되면 오버타임도 멈추고 NeedsExtension 상태로 이동한다.

### 5.5 오버타임 설정값
| 설정 | 기본값 | 설명 |
|---|---:|---|
| 오버타임 사용 | 켜짐 | 턴 종료 후 초과 시간을 측정 |
| 오버타임 표시 | 켜짐 | 화면에 +00:00 형식으로 표시 |
| 오버타임 기준 | 1분 | 패널티 발생 기준 |
| 반복 패널티 | 꺼짐 | 한 턴에 한 번만 패널티 기록 |

## 6. 패널티 규칙
### 6.1 패널티의 정의
패널티는 오버타임이 설정한 기준 이상이 되었을 때 발생하는 기록이다.

기본:
```text
오버타임 >= 60초
=> 패널티 1회
```

### 6.2 패널티는 비난이 아니다
패널티는 누가 잘못했는지 판단하지 않는다. 정한 시간을 넘겼다는 기록이다.

권장 사용자 표현:
- 오버타임 표시
- 주의 표시
- 시간 초과 기록

### 6.3 기본 패널티 반복 규칙
기본은 한 턴에 한 번만 패널티가 발생한다.

예:
```text
패널티 기준 = 60초
오버타임 = 130초
반복 패널티 = 꺼짐
결과 = 패널티 1회
```

반복 패널티를 켜면 기준 시간마다 발생한다.

예:
```text
패널티 기준 = 60초
오버타임 = 130초
반복 패널티 = 켜짐
결과 = 패널티 2회
```

## 7. 알림 규칙
### 7.1 기본 알림
각자의 발언 시간이 10초 남았을 때 알림을 준다.

기본값:
- 턴 시간 10초 전 알림: 켜짐
- 전체 발언 시간 10초 전 알림: 켜짐
- 오버타임 시작 알림: 켜짐
- 패널티 도달 알림: 켜짐

### 7.2 알림 시점은 설정 가능
사용자는 사전 알림 시점을 바꿀 수 있다.

옵션:
- 5초 전
- 10초 전
- 15초 전
- 30초 전
- 직접 입력

### 7.3 알림 방식은 설정 가능
사용자는 알림 방식을 바꿀 수 있다.

옵션:
- 화면 표시
- 소리
- 진동/햅틱
- 조합
- 전체 끄기

### 7.4 알림 중복 방지
같은 이벤트에 대해서는 알림을 한 번만 보낸다.

예:
```text
턴 시간이 10초가 됨
=> TurnWarningEvent 1회
이후 9초, 8초, 7초에는 같은 알림 반복 없음
```

## 8. 기본 진행 예시
설정:
```text
A 전체 시간 = 5분
B 전체 시간 = 5분
턴 제한 = 1분
오버타임 = 켜짐
패널티 기준 = 1분
알림 = 10초 전, 화면 + 진동
첫 발언자 = A
```

진행:
1. A의 차례가 시작된다.
2. A의 전체 시간과 턴 시간이 함께 줄어든다.
3. A의 턴 시간이 10초 남으면 알림이 나온다.
4. A의 턴 시간이 0이 되면 오버타임이 시작된다.
5. A가 차례 넘기기를 누르지 않으면 오버타임이 증가한다.
6. 오버타임이 1분에 도달하면 A에게 패널티 1회가 기록된다.
7. 차례 넘기기를 누르면 B의 차례가 시작된다.
8. B의 턴 시간은 새로 1분으로 시작된다.
9. B의 전체 시간이 줄어든다.
10. 누군가의 전체 시간이 0이 되면 시간 추가 또는 종료를 선택한다.

## 9. 비대칭 시간 예시
설정:
```text
A 전체 시간 = 3분
B 전체 시간 = 7분
턴 제한 = 1분
```

진행:
- A는 전체 대화에서 최대 3분까지 말할 수 있다.
- B는 전체 대화에서 최대 7분까지 말할 수 있다.
- 둘 다 한 번의 차례에서는 기본적으로 1분씩 말한다.
- A의 전체 시간이 0이 되면 A는 시간 추가 동의 없이 더 말할 수 없다.

## 10. 엣지 케이스
### 10.1 턴 제한보다 전체 시간이 짧음
```text
A 전체 남은 시간 = 20초
턴 제한 = 1분
```

A의 실제 정상 발언 가능 시간은 20초다. 전체 시간이 0이 되면 종료/연장 선택으로 이동한다.

### 10.2 오버타임이 꺼져 있음
MVP 기본은 오버타임 켜짐이다. 오버타임을 끄는 경우 후속 옵션이 필요하다.

가능한 동작:
- 턴 종료 시 자동 차례 전환
- 턴 종료 시 자동 휴식

MVP에서는 오버타임 켜짐을 기본으로 구현하고, 끄기 옵션은 단순히 “오버타임 표시와 패널티를 기록하지 않음”으로 처리할 수 있다. 단, 이 경우 턴 종료 시 동작은 제품에서 다시 결정해야 한다.

권장 MVP 결정:
- 오버타임은 기본 켜짐
- 사용자가 끄면 자동 전환 모드를 선택하게 한다

### 10.3 차례 넘기기를 잘못 누름
후속 버전에서 “방금 넘김 취소”를 제공할 수 있다. MVP에서는 실수 방지를 위해 차례 넘기기 버튼을 크고 명확하게 만들되, 즉시 취소는 필수로 보지 않는다.

### 10.4 휴식 중 오버타임
휴식 중에는 오버타임이 증가하지 않는다.

## 11. 구현 우선순위
1. 참가자별 전체 시간
2. 턴 제한
3. 오버타임 카운트
4. 패널티 기준 1분
5. 10초 전 알림 이벤트
6. 알림 방식 설정
7. Wrap-up에서 오버타임/패널티 표시
8. 앱 설정 기본값 저장
