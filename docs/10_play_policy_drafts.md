## 1. 현재 제품/데이터 전제

이 초안은 `시계 (부부싸움 시리즈)` v4 문서의 현재 범위를 기준으로 한다.

- 앱은 두 사람이 같은 총 발언시간과 턴 제한을 두고 번갈아 말하도록 돕는 로컬 타이머다.
- 앱은 누가 옳은지, 누가 잘못했는지, 관계 상태가 어떤지 판단하지 않는다.
- 녹음, 마이크 입력, 음성 감지, 감정 분석, AI 요약, 클라우드 동기화, 사용자 계정은 v4 범위에 없다.
- 대화 기록은 사용자가 직접 저장한 경우 기기 로컬 저장소에만 저장한다.
- 앱 서버로 기록을 전송하거나 제3자에게 공유하지 않는 정책을 기준으로 한다.
- 현재 Android release 기준으로 마이크, 녹음, 위치, 연락처 권한을 요청하지 않는 것을 정책 전제로 한다.

## 4. 개인정보 처리방침 초안

아래 문구는 공개 전 검토가 필요한 초안이다. 실제 공개 시 `TBD` 항목을 실제 값으로 교체해야 한다.

### 개인정보 처리방침

`시계 (부부싸움 시리즈)`는 사용자의 대화 시간을 공평하게 나누는 데 도움을 주는 로컬 타이머 앱입니다. 앱은 상담, 치료, 관계 진단, 감정 분석, 녹음 기능을 제공하지 않으며, 누가 옳거나 그른지 판단하지 않습니다.

#### 수집하는 정보

앱은 v4 범위에서 다음 정보를 서버로 수집하거나 전송하지 않습니다.

- 음성 또는 녹음 파일
- 마이크 입력
- 위치 정보
- 연락처
- 계정 정보
- 대화 내용의 서버 전송 데이터

사용자가 기록 저장을 선택하면 아래 정보가 기기 로컬 저장소에 저장될 수 있습니다.

- 대화 시작/종료 시간
- 사용자가 입력한 참가자 이름
- 참가자별 사용 시간
- 사용자가 입력한 총평
- 사용자가 입력한 해시태그
- 사용자가 선택한 결과값: `잘 마무리됨` 또는 `아직 남음`
- 기존 기록과의 호환성을 위한 내부 패널티 카운트

#### 정보 사용 목적

로컬에 저장된 정보는 사용자가 이전 대화 기록을 다시 확인하고 다음 대화를 준비하는 메모로만 사용됩니다. 앱은 기록을 바탕으로 사용자를 평가하거나, 관계 상태를 진단하거나, 승패/잘못을 판정하지 않습니다.

#### 저장 위치와 공유

저장된 기록은 사용자의 기기 안에만 보관됩니다. 앱은 v4 범위에서 별도 서버, 클라우드 동기화, 외부 분석 서비스로 기록을 전송하지 않습니다. 운영자는 사용자의 로컬 기록에 접근할 수 없습니다.

#### 권한

앱은 v4 범위에서 마이크, 녹음, 카메라, 위치, 연락처 권한을 요청하지 않습니다. 개발/프로파일 빌드에는 Flutter 개발 편의를 위한 `INTERNET` 권한이 포함될 수 있으나, Google Play에 제출하는 release/main AndroidManifest에는 포함하지 않는 것을 자동 검증합니다. 실제 기기 권한 요청 및 Play Console 최종 표시는 릴리스 후보에서 별도로 확인해야 합니다.

#### 삭제

사용자는 앱 안에서 저장한 기록을 삭제할 수 있어야 합니다. 앱을 삭제하면 기기에 저장된 앱 데이터도 운영체제 정책에 따라 삭제됩니다. 삭제 동작은 실제 릴리스 후보에서 다시 확인해야 합니다.

#### 변경

개인정보 처리방침이 변경되면 공개 문서의 내용을 갱신합니다. 녹음, AI 요약, 클라우드 동기화, 계정 기능처럼 개인정보 영향이 커지는 기능을 추가하는 경우 별도 동의, 삭제 기능, 정책 고지를 먼저 검토해야 합니다.

## 5. Google Play 데이터 보안 답변 초안

> 상태: Play Console 실제 선택지는 시점에 따라 바뀔 수 있으므로 제출 전 화면 기준으로 재확인해야 한다.

### 데이터 수집 및 공유

| Play Console 질문 | 초안 답변 | 근거/주의 |
|---|---|---|
| 앱에서 사용자 데이터를 수집하나요? | 아니요 | v4는 로컬 기록만 사용하고 서버 전송이 없다는 전제다. Play의 “수집” 정의가 기기 외부 전송을 뜻하는지 제출 화면에서 재확인한다. |
| 앱에서 사용자 데이터를 공유하나요? | 아니요 | 제3자 SDK/서버/분석 전송을 사용하지 않는 전제다. |
| 앱의 모든 사용자 데이터가 전송 중 암호화되나요? | 해당 없음 또는 예외 없음 | 서버 전송이 없다는 전제다. Play Console이 필수 답변을 요구하면 화면 문구에 맞춰 선택한다. |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 로컬 기록은 앱 내 삭제/앱 삭제로 제거 가능 | 실제 앱의 기록 삭제 UX가 릴리스 후보에서 동작하는지 확인해야 한다. 서버 보관 데이터는 없다는 전제다. |

| 기타 사용자 제작 콘텐츠 | 아니요 | 아니요 | 총평/해시태그는 사용자가 직접 저장할 수 있으나 로컬에만 저장한다. Play Console 분류상 “수집”으로 간주되는지 제출 화면에서 재확인한다. |
