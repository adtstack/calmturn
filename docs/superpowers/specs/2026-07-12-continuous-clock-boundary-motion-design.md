# 연속 시계 경계 이동 설계

- 작성일: 2026-07-12
- 대상: 실행 화면의 좌우 시계 경계 이동
- 상태: 사용자 승인 설계

## 1. 목적

턴이 바뀔 때 시계 경계가 중앙으로 순간 이동하는 동작을 없앤다. 경계는 사용자가 보고 있던 위치를 그대로 유지하고, 새 발언자의 현재 화면 영역을 새 턴의 전체 이동거리로 사용한다.

시간 계산과 턴 규칙은 바꾸지 않는다. 이번 변경은 실행 화면의 경계 위치와 애니메이션 의미만 수정한다.

## 2. 현재 문제

현재 실행 화면은 턴마다 시각 진행값을 초기화하고, 새 발언자의 경계를 다시 50%에서 계산한다. 또한 턴 식별자가 바뀔 때 `TweenAnimationBuilder`가 새 인스턴스로 만들어져 이전 프레임의 실제 경계 위치를 이어받지 못한다.

예를 들어 A가 화면의 25% 지점까지 사용한 뒤 턴을 넘기면 경계가 즉시 50%로 이동하고, B의 턴 이동이 50%부터 다시 시작한다. 이 순간 이동은 대화 흐름의 시각적 연속성을 깨뜨린다.

현재 애니메이션은 1초 단위 상태 갱신마다 700ms 동안 감속 이동한 뒤 남은 시간 동안 멈추는 방식이다. 경계 초기화 문제를 제거하더라도 이 방식만 유지하면 완전히 연속적인 이동은 만들 수 없다.

## 3. 확정된 UX 규칙

### 3.1 기본 규칙

- 세션 시작 경계는 화면의 50%다.
- 경계 위치는 화면 폭에 대한 `0.0..1.0` 비율로 관리한다.
- A가 발언하면 경계는 현재 위치에서 왼쪽 끝 `0.0`을 향한다.
- B가 발언하면 경계는 현재 위치에서 오른쪽 끝 `1.0`을 향한다.
- 새 발언자의 현재 영역 전체를 그 턴의 100% 이동거리로 사용한다.
- 경계는 턴 남은 시간에 맞춰 등속으로 이동한다.
- 턴이 바뀌는 순간에는 현재 화면에 그려진 정확한 위치를 유지하고 이동 방향만 바꾼다.
- 중앙 복귀 애니메이션이나 중앙 위치 초기화는 사용하지 않는다.

### 3.2 예시

1. A가 50%에서 시작해 25%까지 이동한 뒤 턴을 넘긴다.
2. 경계는 25%에 그대로 머문다.
3. B의 현재 영역인 25%부터 100%까지의 75% 폭을 B의 새 턴 이동거리로 사용한다.
4. B가 턴을 절반 사용하면 경계는 약 62.5%에 있다.
5. B가 60% 지점에서 일찍 턴을 넘기면 A는 60%부터 0%를 향해 이동한다.

## 4. 검토한 구현 방식

### 4.1 연속 애니메이션 컨트롤러 — 채택

실제 렌더링 중인 경계 비율을 보존하는 `AnimationController`를 사용한다. 새 턴이 시작되면 현재 컨트롤러 값을 시작점으로 삼고, 새 발언자가 위치한 쪽의 바깥 화면 끝을 목표로 남은 턴 시간 동안 선형 이동한다.

장점:

- 애니메이션 도중 턴을 넘겨도 위치가 끊기지 않는다.
- 1초 단위의 이동과 정지 반복이 사라진다.
- 일시정지와 재개 시 실제 보이는 위치를 정확히 보존할 수 있다.
- 화면 크기가 바뀌어도 비율 값은 그대로 유지된다.

비용:

- 시계 레이아웃이 자체 애니메이션 생명주기를 관리해야 한다.
- 타이머 스냅샷의 단계 변화와 애니메이션 상태를 명시적으로 동기화해야 한다.

### 4.2 기존 암시적 애니메이션의 목표값만 변경 — 제외

기존 `TweenAnimationBuilder`의 턴별 키를 제거하고 새 목표값을 계산하는 최소 변경이다. 중앙 순간 이동은 줄일 수 있지만 1초마다 감속 이동과 정지가 반복되고, 이동 도중 전환할 때 정확한 화면 위치를 상태로 다루기 어렵다.

### 4.3 참가자별 총 잔여시간 비율 사용 — 제외

경계를 두 참가자의 총 잔여시간 비율로 계산하면 턴 전환 때 값은 이어진다. 그러나 현재 영역을 한 턴 동안 사용하는 확정된 의미와 맞지 않고, 턴 시간과 경계 이동의 관계도 약해진다.

## 5. 구조

### 5.1 책임 분리

- `TimerEngine`은 총 시간, 턴 시간, 오버타임, 자동 전환과 일시정지 상태를 계속 관리한다.
- `TimerHomePage`는 엔진 이벤트, 화면 갱신, 세션 생명주기를 계속 관리한다.
- `_ClockZoneLayout`은 상태가 있는 위젯으로 전환해 경계의 실제 표시 비율과 애니메이션을 소유한다.
- 시간 숫자, 상태 문구, 위험 점멸과 접근성 정보는 계속 `TimerSnapshot`을 사용한다.
- 배경 영역의 너비만 애니메이션 컨트롤러 값을 사용한다.

타이머 도메인 모델에는 화면 좌표나 애니메이션 상태를 추가하지 않는다.

### 5.2 세션과 턴 식별

- 새 세션이 시작될 때만 경계 상태를 새로 만들고 50%로 초기화한다.
- 턴 전환에는 위젯 키를 바꾸지 않는다.
- 현재의 턴별 `turnVisualVersion`과 `turnVisualTotalSeconds` 상태는 제거한다.
- 세션을 같은 화면 상태에서 재시작할 가능성에 대비해 세션 단위 식별자만 경계 위젯의 재생성에 사용한다.

### 5.3 애니메이션 입력

경계 애니메이션은 다음 값만 입력으로 사용한다.

- 현재 발언자 ID
- A 참가자 ID
- 현재 턴 남은 시간
- 현재 타이머 단계
- 세션 단위 식별자

A가 현재 발언자면 목표는 `0.0`, B가 현재 발언자면 목표는 `1.0`이다. 애니메이션 시작값은 계산식으로 다시 만들지 않고 컨트롤러의 현재 표시값을 사용한다.

남은 턴 시간이 0이면 새 애니메이션을 시작하지 않고 현재 단계의 끝 위치를 유지한다. 위젯이 제거되면 컨트롤러도 함께 해제해 화면 밖에서 애니메이션이 계속되지 않게 한다.

## 6. 상태별 동작

### 6.1 세션 시작

경계를 `0.5`로 설정한다. 첫 발언자를 확인하고 현재 턴 남은 시간 동안 해당 발언자 방향의 화면 끝까지 선형 애니메이션을 시작한다.

### 6.2 정상 진행

애니메이션은 턴 전체 시간 동안 멈춤 없이 진행한다. 엔진의 1초 틱은 숫자와 이벤트를 갱신하지만 매 틱마다 경계 위치를 다시 설정하지 않는다.

프레임 지연이나 타이머 스케줄 오차가 발생해도 현재 표시값을 덮어쓰지 않는다. 다음 상태 변화에서는 항상 그 표시값을 새 시작점으로 사용한다.

### 6.3 수동 또는 자동 턴 전환

현재 애니메이션을 멈추되 값을 초기화하지 않는다. 새 발언자의 목표 끝점을 정하고, 새 턴 남은 시간 동안 현재 값부터 반대 방향으로 애니메이션을 시작한다.

수동 전환과 `autoSwitch`는 같은 시각 규칙을 사용한다.

### 6.4 일시정지와 재개

- 일시정지 시 컨트롤러를 현재 값에서 멈춘다.
- 일시정지 중에는 경계가 움직이지 않는다.
- 재개 시 현재 값부터 기존 발언자의 목표 끝점까지 엔진이 가진 현재 턴 남은 시간을 사용해 다시 이동한다.

### 6.5 턴 종료와 오버타임

정상 턴 시간을 모두 사용하면 경계는 현재 발언자 쪽 화면 끝에 도달한다. 오버타임 동안은 그 위치를 유지한다. 오버타임에서 턴을 넘기면 화면 끝의 현재 위치부터 반대쪽 끝을 향해 새 턴 이동을 시작한다.

`autoPause`로 멈춘 경우에도 경계는 끝 위치를 유지하고, 다음 유효한 턴이 시작될 때만 움직인다.

### 6.6 총 시간 종료와 세션 종료

현재 턴 시간은 참가자의 남은 총 시간보다 길 수 없으므로 총 시간이 먼저 끝나는 턴도 같은 목표 끝점에 도달한다. `needsExtension` 또는 `finished`에서는 컨트롤러를 멈추고 현재 위치를 보존한다.

## 7. 렌더링과 접근성

- 왼쪽 배경 너비는 `전체 폭 * 경계 비율`이다.
- 오른쪽 배경 너비는 나머지 폭이다.
- 읽기 영역과 전체 화면 탭 영역은 지금처럼 좌우 절반에 고정한다.
- 참가자 이름과 시간 숫자는 경계와 함께 이동하거나 축소하지 않는다.
- 기존의 전경색과 반대색 그림자를 유지해 경계가 어느 절반에 있더라도 숫자를 읽을 수 있게 한다.
- 화면 크기 변경 시 컨트롤러 비율은 유지하고 새 전체 폭에 다시 적용한다.
- 비정상 값은 렌더링 직전에 `0.0..1.0`으로 제한한다.

## 8. 검증

위젯 테스트에서 다음 계약을 고정한다.

1. 세션이 50%에서 시작하고 첫 발언자 방향으로 연속 이동한다.
2. A가 25%에서 턴을 넘기면 다음 프레임에도 25%를 유지하며 50%로 이동하지 않는다.
3. B가 25%에서 시작해 턴을 절반 사용하면 경계가 약 62.5%에 도달한다.
4. 애니메이션 프레임 중간에 수동 전환해도 전환 전후 위치 차이가 허용 오차 안에 있다.
5. 여러 번 일찍 턴을 넘겨도 매번 직전 위치에서 방향만 바뀐다.
6. 일시정지 동안 경계가 고정되고 재개 후 같은 위치부터 움직인다.
7. `autoSwitch`가 수동 전환과 같은 연속 이동을 사용한다.
8. 오버타임과 `autoPause`에서 경계가 끝 위치를 유지한다.
9. 총 시간 종료와 `needsExtension`에서 경계가 움직이지 않는다.
10. 화면 폭 변경 전후 경계 비율이 유지된다.
11. 시간 읽기 영역, 전체 탭 영역, 위험 점멸과 접근성 레이블의 기존 동작이 유지된다.

전체 저장소 검증은 `./tool/check.sh`로 실행한다.

## 10. 범위 제외

- 턴 제한, 총 시간, 오버타임과 패널티 규칙 변경
- 참가자별 시간 계산 또는 기록 형식 변경
- 시계 색상, 글꼴, 문구, 조작 버튼 배치 변경
- 최소 영역 폭 도입
- 상업 배포, 광고 또는 Pro 기능 구현
