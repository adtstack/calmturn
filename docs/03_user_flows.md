# 03. User Flows & Information Architecture

## 정보 구조

### Home
- 새 대화 시작
- 빠른 시작
- 최근 기록
- 설정

### New Session
- 대화 유형 선택
- 참가자 이름 입력
- 전체 발언 시간 설정
  - 같은 시간
  - 각자 다르게
- 턴당 발언 제한 설정
- 첫 발언자 설정
- 오버타임 설정
- 패널티 설정
- 알림 설정
- 규칙 확인

### Consent
- 참가자 A 동의
- 참가자 B 동의
- 시작

### Timer
- 참가자 A 영역
- 참가자 B 영역
- 각자의 전체 남은 시간
- 현재 턴 남은 시간
- 오버타임 표시
- 패널티 표시
- 현재 발언자 표시
- 차례 넘기기
- 휴식
- 종료

### Break
- 휴식 중 문구
- 재개
- 종료

### Time Extension
- 누구에게 시간을 더할지 선택
- 추가 시간 선택
- 양쪽 동의

### Wrap-up
- 종료 사유
- 각자 사용한 전체 시간
- 각자 남은 전체 시간
- 각자 오버타임 합계
- 각자 패널티 횟수
- 합의한 것
- 다음에 이야기할 것
- 저장/삭제

### History
- 최근 대화 기록
- 기록 상세
- 기록 삭제

### Settings
- 기본 전체 발언 시간
- 기본 턴 제한
- 기본 오버타임 설정
- 기본 패널티 기준
- 기본 알림 설정
- 소리/진동/화면 표시
- 개인정보/기록 삭제

## 기본 사용자 흐름

### Flow 1. 빠른 시작
1. Home에서 “빠른 시작”을 누른다.
2. 기본 규칙이 표시된다.
   - 각자 5분
   - 턴당 1분
   - 오버타임 켜짐
   - 오버타임 1분 이상 패널티
   - 10초 전 화면+진동 알림
3. 두 사람이 동의한다.
4. Timer 화면으로 이동한다.
5. 첫 발언자가 말한다.
6. 10초 남으면 알림이 나온다.
7. 턴 시간이 끝나면 오버타임이 시작된다.
8. 차례 넘기기를 누르면 상대 차례가 된다.
9. 종료 후 Wrap-up으로 이동한다.

### Flow 2. 새 대화 — 같은 전체 시간
1. Home에서 “새 대화 시작”을 누른다.
2. 대화 유형을 선택한다.
3. 참가자 이름을 입력한다.
4. 전체 발언 시간에서 “같은 시간”을 선택한다.
5. 각자 5분 또는 다른 프리셋을 고른다.
6. 턴당 제한을 선택한다.
7. 오버타임/패널티/알림 기본값을 확인한다.
8. Consent에서 양쪽이 동의한다.
9. Timer 화면으로 이동한다.

### Flow 3. 새 대화 — 각자 다른 전체 시간
1. Home에서 “새 대화 시작”을 누른다.
2. 참가자 이름을 입력한다.
3. 전체 발언 시간에서 “각자 다르게”를 선택한다.
4. 참가자 A 시간을 입력한다.
5. 참가자 B 시간을 입력한다.
6. 화면에 다음 문구를 보여준다.
   - “서로 동의한 시간 배분입니다.”
   - “시작 전 두 사람이 모두 확인해주세요.”
7. 턴당 제한과 오버타임 설정을 고른다.
8. Consent 화면에서 각자 시간이 명확히 보인다.
9. 양쪽 동의 후 시작한다.

### Flow 4. 오버타임 발생
1. A의 차례가 시작된다.
2. A의 턴 시간이 줄어든다.
3. 턴 시간이 10초 남으면 알림이 나온다.
4. 턴 시간이 0이 된다.
5. 화면이 오버타임 상태로 전환된다.
   - “오버타임 +00:01”
   - “차례를 넘길 준비가 되었나요?”
6. A가 계속 말하거나 차례 넘기기를 누르지 않으면 오버타임이 증가한다.
7. 오버타임이 1분이 되면 패널티가 1회 기록된다.
8. A 또는 B가 “차례 넘기기”를 누르면 B의 차례가 시작된다.

### Flow 5. 10초 전 알림
1. 현재 턴 남은 시간이 설정값에 도달한다.
2. 설정된 알림 방식에 따라 알림을 준다.
   - 화면 표시만
   - 소리만
   - 진동/햅틱만
   - 조합
3. 알림은 한 이벤트에 한 번만 발생한다.
4. 전체 발언 시간이 10초 남은 경우에도 설정이 켜져 있으면 알림을 준다.

### Flow 6. 전체 시간이 끝남
1. A의 전체 발언 시간이 0이 된다.
2. 타이머가 멈춘다.
3. 화면에 선택지를 보여준다.
   - 오늘은 여기까지
   - A에게 시간 추가
   - 양쪽에게 시간 추가
   - 휴식
4. 시간 추가는 기본적으로 양쪽 동의가 필요하다.

### Flow 7. 휴식
1. 누구든 휴식 버튼을 누른다.
2. 모든 시간 계산이 멈춘다.
3. “잠깐 쉬는 중입니다” 화면이 나온다.
4. 재개 또는 종료를 선택한다.
5. 재개하면 기존 발언자와 기존 턴 상태로 돌아간다.

### Flow 8. 대화 종료와 기록
1. 종료 버튼을 누른다.
2. 종료 확인 화면이 나온다.
3. Wrap-up으로 이동한다.
4. 시간 사용 요약을 본다.
5. 합의한 것과 다음에 이야기할 것을 입력한다.
6. 저장하거나 저장하지 않고 나간다.

## Timer 상태 흐름
```text
Draft
  -> WaitingConsent
  -> Running.Normal
  -> Running.Warning
  -> Running.Overtime
  -> Running.PenaltyMarked
  -> Paused
  -> Running.Normal / Running.Overtime
  -> Finished
```

## 화면 내 상태 정의
### Normal
- 턴 시간이 남아 있다.
- 현재 발언자의 전체 시간과 턴 시간이 줄어든다.

### Warning
- 설정된 사전 알림 시점에 도달했다.
- 예: 10초 남음
- 알림을 준 뒤 Normal 상태로 계속 진행한다.

### Overtime
- 턴 시간이 0이 됐다.
- 오버타임이 증가한다.
- 현재 발언자의 전체 시간이 남아 있다면 전체 시간도 계속 줄어든다.

### PenaltyMarked
- 오버타임이 패널티 기준에 도달했다.
- 패널티가 기록된다.
- 화면에 짧게 표시한 뒤 Overtime 상태가 계속된다.

### Paused
- 휴식 또는 일시정지 상태다.
- 모든 시간 계산이 멈춘다.

### Finished
- 세션이 종료됐다.
- Wrap-up으로 이동한다.

## 주요 예외 흐름
### 턴 시간보다 전체 남은 시간이 짧은 경우
- 예: A의 전체 시간이 20초 남았고 턴 제한은 1분이다.
- 실제 발언 가능 시간은 20초다.
- 전체 시간이 10초 남으면 전체 시간 알림을 준다.
- 전체 시간이 0이 되면 타이머를 멈춘다.

### 오버타임 중 전체 시간이 0이 되는 경우
- 오버타임은 중단된다.
- 전체 시간 종료 상태로 이동한다.
- 시간 연장 또는 종료 선택지를 보여준다.

### 휴식 중 알림
- 휴식 중에는 알림이 발생하지 않는다.
- 재개 후 조건에 도달하면 알림을 발생시킨다.

### 알림이 꺼져 있는 경우
- 화면 표시, 소리, 진동이 모두 꺼져 있으면 어떤 피드백도 주지 않는다.
- 단, 타이머 숫자는 계속 갱신된다.
