# 03. User Flows & Information Architecture

## 정보 구조

### Home
- 새 대화 시작
- 빠른 시작
- 최근 기록
- 설정

### New Session
- 대화 유형 선택
- 참가자 이름 입력
- 시간 설정
- 규칙 확인

### Consent
- 참가자 A 동의
- 참가자 B 동의
- 시작

### Timer
- 참가자 A 영역
- 참가자 B 영역
- 현재 발언자 표시
- 차례 넘기기
- 휴식
- 종료

### Break
- 휴식 중 문구
- 재개
- 종료

### Wrap-up
- 종료 사유
- 합의한 것
- 남은 것
- 다음 대화
- 저장

### History
- 세션 목록
- 세션 상세
- 삭제

### Settings
- 기본 시간
- 알림음/진동
- 데이터 삭제
- 개인정보 안내
- 지원/문의

## Flow 1 — 빠른 시작
1. 사용자가 홈에서 “빠른 시작”을 누른다.
2. 기본값: A/B, 각 5분, 총량 모드.
3. 동의 화면으로 이동한다.
4. 양쪽이 동의한다.
5. 타이머 화면이 시작된다.
6. 대화 후 종료 회고를 저장한다.

## Flow 2 — 커스텀 세션
1. 사용자가 “새 대화 시작”을 누른다.
2. 대화 유형을 선택한다.
3. 두 사람의 이름을 입력한다.
4. 각자 시간을 설정한다.
5. 규칙을 확인한다.
6. 양쪽이 동의한다.
7. 타이머가 시작된다.

## Flow 3 — 휴식
1. 대화 중 한 사람이 “휴식”을 누른다.
2. 모든 타이머가 멈춘다.
3. 화면에 “잠깐 쉬어도 괜찮아요”가 표시된다.
4. 재개 버튼을 누른다.
5. 기본 설정에 따라 양쪽 동의 후 재개된다.

## Flow 4 — 시간 종료
1. 현재 발언자의 시간이 0이 된다.
2. 부드러운 알림이 울린다.
3. 앱은 “시간이 끝났어요. 마무리할까요?”를 표시한다.
4. 사용자는 종료하거나, 추가 시간을 선택한다.
5. 추가 시간은 양쪽 동의가 필요하다.

## Flow 5 — 기록 보기
1. 홈에서 최근 기록을 누른다.
2. 세션 상세에서 각자 사용 시간과 메모를 본다.
3. 기록을 삭제할 수 있다.

## 사용자 여정

### 시작 전
- 기대: “이번엔 덜 싸우고 싶다.”
- 앱 역할: 부담 없이 규칙을 제안한다.
- 중요한 문구: “두 사람이 모두 동의해야 시작돼요.”

### 대화 중
- 기대: “내 차례를 지켜줬으면 좋겠다.”
- 앱 역할: 누가 말할 차례인지 명확히 보여준다.
- 중요한 문구: “지금은 들어주는 시간이에요.”

### 감정이 올라올 때
- 기대: “잠깐 멈추고 싶다.”
- 앱 역할: 멈춤을 정당화한다.
- 중요한 문구: “휴식은 포기가 아니에요.”

### 끝난 뒤
- 기대: “그래서 뭘 정했지?”
- 앱 역할: 결론만 가볍게 남긴다.
- 중요한 문구: “오늘의 작은 합의만 적어도 충분해요.”
