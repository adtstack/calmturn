# 03. User Flows & Information Architecture - v4

## 정보 구조

### 시작/설정
- 참가자 이름
- 각자 총 발언시간
- 턴 제한
- 첫 발언자
- 고급설정 버튼
- 저장된 기록 보기
- 시작

### 고급설정
- 전체 시간 세부 규칙
- 오버타임
- 알림
- 내부 패널티 기록 설정
- 기록 자동 저장

### 실행
- 좌우 2분할 시계
- 왼쪽/오른쪽 전체 탭 영역
- 일시정지
- 종료
- 종료 확인창

### 마무리
- 대화 요약
- 참가자별 사용 시간
- 총평
- 해시태그
- 결과 선택
- 기록 저장
- 새 대화
- 기록 보기

### 기록
- 기록 달력
- 일자별 기록 목록
- 기록 상세

## Flow 1. 빠른 시작
1. 앱을 연다.
2. 기본 이름 `남편`, `와이프`가 보인다.
3. 기본 시간 `각자 10분`, 턴 `3분`이 보인다.
4. 첫 발언자를 확인한다.
5. `시작`을 누른다.
6. 실행 화면으로 바로 이동한다.

## Flow 2. 설정 후 시작
1. 이름을 수정한다.
2. 각자 총 발언시간을 `10 / 20 / 30 / 60분` 중 고른다.
3. 턴 제한을 `1 / 3 / 5 / 10분` 중 고른다.
4. 첫 발언자를 고른다.
5. `시작`을 누른다.
6. 유효하지 않은 설정이면 시작 화면에서 메시지를 보여준다.

## Flow 3. 고급설정 변경
1. 시작 화면에서 톱니바퀴를 누른다.
2. 고급설정 화면에서 세부 규칙을 바꾼다.
3. 뒤로 간다.
4. 유효한 설정이면 자동 저장된다.
5. 시작 화면에는 핵심 설정만 남는다.

## Flow 4. 실행 중 차례 넘기기
1. 첫 발언자의 영역이 활성 상태로 보인다.
2. 현재 발언자의 턴 시간이 줄어든다.
3. 현재 발언자의 총 남은 시간이 줄고 영역 폭도 함께 줄어든다.
4. 화면 영역을 탭하면 차례가 상대에게 넘어간다.
5. 상대의 턴 시간이 새로 시작된다.

## Flow 5. 일시정지와 재개
1. 실행 중 `일시정지`를 누른다.
2. 시간이 멈춘다.
3. 버튼은 재개 가능한 상태를 보여준다.
4. 다시 누르면 같은 상태에서 이어진다.

## Flow 6. 종료와 마무리
1. 실행 중 `종료`를 누른다.
2. 확인창이 열린다.
3. 취소하면 실행 화면으로 돌아간다.
4. 종료를 확정하면 마무리 화면으로 이동한다.
5. 총평, 해시태그, 결과를 입력한다.
6. 기록 저장 또는 저장하지 않고 마치기를 선택한다.

## Flow 7. 기록 보기
1. 시작 화면 또는 마무리 화면에서 기록 보기를 연다.
2. 기록 달력에서 날짜별 O/X를 확인한다.
3. 날짜를 누르면 일자별 기록 목록이 열린다.
4. 기록을 누르면 상세 화면이 열린다.
5. 상세 화면에서 시간, 총평, 해시태그, 결과, 참가자별 사용 시간을 확인한다.

## 상태 흐름
```text
Setup
  -> Running.Normal
  -> Running.Overtime
  -> Paused
  -> Finished
  -> WrapUp
  -> History
```

## 예외 흐름
- 턴 제한이 전체 시간보다 길면 시작 전 검증 메시지를 보여준다.
- 오버타임을 끈 경우 턴 종료 시 자동 휴식 상태로 들어갈 수 있다.
- 기록 필드가 없는 기존 로컬 기록은 빈 총평/해시태그/결과로 읽는다.
