# 04. Screen Specs - v4

## 1. 시작/설정 화면

### 목적
최소 입력으로 바로 대화 시계를 시작한다.

### 구성
- 상단 제목: `시계`
- 우상단 톱니바퀴: 고급설정
- 저장된 기록 보기
- 참가자 이름 입력
  - 왼쪽: 기본 `남편`
  - 오른쪽: 기본 `와이프`
- 전체 시간 프리셋
  - `각자 10분`
  - `각자 20분`
  - `각자 30분`
  - `각자 60분`
- 턴 제한 프리셋
  - `턴 1분`
  - `턴 3분`
  - `턴 5분`
  - `턴 10분`
- 첫 발언자 선택
- `시작` 버튼

### 검증
- 턴 제한이 전체 시간보다 길면 시작하지 않는다.
- 잘못된 직접 입력 범위는 안내 메시지를 보여준다.
- 시작 전 별도 동의 화면은 없다.

## 2. 고급설정 화면

### 목적
시작 화면을 복잡하게 만들지 않고 세부 규칙을 조정한다.

### 구성
- 전체 시간 세부 설정
- 턴 제한 세부 설정
- 오버타임 사용 여부와 동작 설명
- 내부 패널티 기록 기준
- 알림 대상과 방식
- 자동 저장

### 동작
- 별도 저장 버튼을 두지 않는다.
- 뒤로 가면 유효한 설정을 자동 저장한다.
- 유효하지 않은 설정은 저장하지 않고 안내한다.

## 3. 실행 화면

### 목적
누가 말하는지, 얼마나 남았는지, 언제 차례를 넘길지만 보여준다.

### 구성
- 좌우 2분할 화면
- 왼쪽 참가자 영역
- 오른쪽 참가자 영역
- 영역 전체 탭으로 차례 넘기기
- 상단 `일시정지`
- 상단 `종료`

### 표시
- 시작 폭은 50:50이다.
- 현재 발언자의 턴 남은 시간을 크게 보여준다.
- 듣는 사람은 총 남은 시간을 보여준다.
- 현재 발언자의 총 남은 시간이 줄수록 해당 영역 폭도 줄어든다.
- 패널티/주의 문구는 표시하지 않는다.

### 종료
- `종료`를 누르면 확인창을 띄운다.
- 확인창에서 종료를 확정해야 마무리 화면으로 간다.

## 4. 마무리 화면

### 목적
대화를 평가하지 않고 다음 대화를 위해 짧게 기록한다.

### 구성
- 대화 시간 요약
- 참가자별 사용 시간
- 총평 입력
- 해시태그 입력
- 결과 선택
  - `잘 마무리됨`
  - `아직 남음`
- 기록 저장
- 저장하지 않고 마치기
- 새 대화
- 기록 보기

## 5. 기록 달력

### 목적
날짜별 대화 결과를 빠르게 스캔한다.

### 구성
- 제목: `기록 달력`
- 날짜 카드
- 날짜 아래 결과 표시
  - `O`: 잘 마무리됨
  - `X`: 아직 남음
  - `-`: 결과 없음
- 날짜별 표시는 최대 3개까지다.

## 6. 일자별 기록

### 목적
특정 날짜의 기록을 자연스럽게 훑는다.

### 구성
- 날짜 제목
- 기록 카드 목록
- 각 카드에는 시작 시간, 결과, 총평, 해시태그를 보여준다.

## 7. 기록 상세

### 목적
한 대화의 전체 기록을 확인한다.

### 구성
- 시작 시간
- 대화 시간
- 결과
- 총평
- 해시태그
- 참가자별 배정 시간
- 참가자별 사용 시간
- 참가자별 남은 시간
- 차례 수
- 오버타임 합계

## 8. 접근성
- 핵심 상태는 색상만으로 전달하지 않는다.
- 큰 글씨에서도 버튼과 시간 텍스트가 겹치지 않아야 한다.
- 실행 화면의 터치 영역은 충분히 커야 한다.
- 종료는 실수 방지를 위해 확인창을 유지한다.
