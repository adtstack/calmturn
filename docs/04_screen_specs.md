# 04. Screen Specs

## 1. Home Screen
### 목적
사용자가 빠르게 대화 세션을 시작한다.

### 구성
- 앱 로고/이름: 말차례 CalmTurn
- 큰 버튼: “새 대화 시작”
- 작은 버튼: “5분씩 · 1분 턴 빠른 시작”
- 최근 기록 카드 1~3개
- 설정 아이콘

### 카피
- 제목: “말할 차례를 나눠볼까요?”
- 설명: “서로 동의한 시간 안에서 차례대로 말해요.”

### 액션
- 새 대화 시작 → New Session
- 빠른 시작 → Consent
- 최근 기록 → History Detail
- 설정 → Settings

## 2. New Session Screen
### 목적
대화의 기본 시간 규칙을 설정한다.

### 필드
- 대화 유형
  - 부부/연인
  - 가족
  - 회의
  - 토론
  - 직접 설정
- 참가자 A 이름
- 참가자 B 이름
- 전체 발언 시간 모드
  - 같은 시간
  - 각자 다르게
- 전체 발언 시간 프리셋
  - 각자 3분
  - 각자 5분
  - 각자 10분
  - 각자 15분
  - 직접 입력
- 각자 다르게 선택 시
  - A 전체 발언 시간
  - B 전체 발언 시간
- 턴당 발언 제한 프리셋
  - 30초
  - 45초
  - 1분
  - 1분 30초
  - 2분
  - 직접 입력
- 첫 발언자
- 다음 버튼

### 카피
- 제목: “시간 규칙을 정해요”
- 보조: “같은 시간으로 시작하거나, 서로 동의한 만큼 다르게 설정할 수 있어요.”

### 검증
- 이름 미입력 시 기본 이름 제안
- 시간은 0초보다 커야 함
- 참가자별 전체 시간이 다르면 Consent에서 다시 강조

## 3. Overtime & Penalty Settings Screen
### 목적
턴 제한을 넘겼을 때 어떻게 기록할지 설정한다.

### 필드
- 오버타임 사용
  - 켜짐/꺼짐
- 오버타임 표시
  - 켜짐/꺼짐
- 패널티 기준
  - 15초
  - 30초
  - 1분
  - 2분
  - 직접 입력
- 반복 패널티
  - 꺼짐: 한 턴에 1회만
  - 켜짐: 기준 시간마다 반복
- 패널티 명칭
  - 오버타임 표시
  - 주의 표시
  - 패널티
- 엄격 모드
  - MVP에서는 비활성 또는 추후 제공
  - 후보: 기준 도달 시 자동 휴식, 자동 차례 전환

### 기본값
- 오버타임 사용: 켜짐
- 패널티 기준: 1분
- 반복 패널티: 꺼짐
- 패널티 명칭: 오버타임 표시

### 카피
- 제목: “말이 길어질 때의 규칙”
- 설명: “차례를 넘기지 않으면 오버타임이 기록됩니다.”
- 도움말: “패널티는 사람을 평가하는 점수가 아니라, 정한 시간을 넘긴 기록입니다.”

## 4. Alert Settings Screen
### 목적
시간이 얼마 남았을 때 어떤 방식으로 알려줄지 설정한다.

### 필드
- 사전 알림 시점
  - 5초 전
  - 10초 전
  - 15초 전
  - 30초 전
  - 직접 입력
- 알림 대상
  - 턴 시간 종료 전
  - 전체 발언 시간 종료 전
  - 오버타임 시작
  - 패널티 기준 도달
- 알림 방식
  - 화면 표시
  - 소리
  - 진동/햅틱
- 소리 종류
  - 부드러운 알림음
  - 짧은 알림음
  - 무음
- 진동 강도
  - 약함
  - 기본
  - 강함
  - 꺼짐

### 기본값
- 사전 알림 시점: 10초 전
- 턴 시간 알림: 켜짐
- 전체 시간 알림: 켜짐
- 오버타임 시작 알림: 켜짐
- 패널티 기준 알림: 켜짐
- 화면 표시: 켜짐
- 진동/햅틱: 켜짐
- 소리: 꺼짐 또는 부드러운 소리

### 카피
- 제목: “알림 방식을 정해요”
- 설명: “소리, 진동, 화면 표시 중 편한 방식을 고를 수 있어요.”

## 5. Consent Screen
### 목적
두 사람이 규칙을 보고 동의한다.

### 구성
- 참가자 이름
- 각자의 전체 발언 시간
- 턴당 발언 제한
- 오버타임 사용 여부
- 패널티 기준
- 사전 알림 시점
- 알림 방식
- 첫 발언자
- 동의 체크 박스 또는 버튼 2개

### 카피
- 제목: “두 사람이 같은 규칙을 보고 시작해요”
- 안내:
  - “내 차례에는 말하고, 상대 차례에는 듣습니다.”
  - “차례를 넘기지 않으면 오버타임이 기록됩니다.”
  - “불편하면 언제든 휴식하거나 종료할 수 있습니다.”
- 비대칭 시간일 때 추가 문구:
  - “이번 대화는 서로 다른 전체 발언 시간으로 설정되어 있습니다.”

### 액션
- 참가자 A 동의
- 참가자 B 동의
- 둘 다 동의 후 시작 버튼 활성화

## 6. Timer Screen
### 목적
대화 중 차례와 시간을 가장 명확하게 보여준다.

### 구성
- 상단: 대화 이름 또는 유형
- 참가자 A 카드
  - 이름
  - 전체 남은 시간
  - 사용한 시간
  - 오버타임 합계
  - 패널티 횟수
- 참가자 B 카드
  - 이름
  - 전체 남은 시간
  - 사용한 시간
  - 오버타임 합계
  - 패널티 횟수
- 중앙: 현재 발언자
- 중앙 큰 숫자: 현재 턴 남은 시간
- 오버타임 상태일 때 중앙 큰 숫자: 오버타임 +00:00
- 버튼
  - 차례 넘기기
  - 잠깐 쉬기
  - 종료

### Normal 상태 표시
- 현재 발언자 카드 강조
- “이번 차례 00:42 남음”
- “전체 시간 04:12 남음”

### Warning 상태 표시
- “10초 남았습니다”
- 설정에 따라 소리/진동/화면 피드백
- 카피는 짧고 부드럽게

### Overtime 상태 표시
- “오버타임 +00:12”
- “차례를 넘길 준비가 되었나요?”
- 색상과 움직임은 너무 공격적이지 않게

### Penalty 상태 표시
- “오버타임 기준에 도달했어요”
- “주의 표시 1회 기록” 또는 설정 명칭 적용
- 2초 정도 표시 후 오버타임 표시로 복귀

### 전체 시간 종료 상태
- “A님의 전체 시간이 끝났어요”
- 버튼:
  - 오늘은 여기까지
  - 시간 추가
  - 휴식

## 7. Break Screen
### 목적
감정이 올라왔거나 잠시 멈추고 싶을 때 안전하게 쉬게 한다.

### 구성
- 제목: “잠깐 쉬는 중입니다”
- 설명: “쉬는 동안 모든 시간이 멈춥니다.”
- 휴식 경과 시간
- 버튼
  - 이어서 하기
  - 오늘은 여기까지

### 동작
- 전체 시간 멈춤
- 턴 시간 멈춤
- 오버타임 멈춤
- 알림 중지

## 8. Time Extension Screen
### 목적
전체 시간이 끝났거나 대화가 더 필요한 경우 시간을 추가한다.

### 구성
- 누구에게 시간을 추가할지
  - A에게 추가
  - B에게 추가
  - 둘 다 추가
- 추가 시간
  - 1분
  - 3분
  - 5분
  - 직접 입력
- 동의 버튼
  - A 동의
  - B 동의

### 카피
- 제목: “시간을 더할까요?”
- 설명: “시간 추가는 두 사람이 동의할 때만 진행됩니다.”

## 9. Wrap-up Screen
### 목적
대화를 마무리하고 기록을 남긴다.

### 구성
- 오늘의 대화 시간 요약
- 참가자별 카드
  - 사용한 전체 시간
  - 남은 전체 시간
  - 턴 횟수
  - 오버타임 합계
  - 패널티 횟수
- 휴식 횟수
- 합의한 것 입력
- 다음에 이야기할 것 입력
- 저장
- 저장하지 않고 종료

### 카피
- 제목: “오늘의 대화를 정리해요”
- 설명: “승패가 아니라, 다음 대화를 위한 기록입니다.”

## 10. History Detail Screen
### 목적
이전 대화 기록을 확인한다.

### 표시
- 날짜와 시간
- 대화 유형
- 참가자 별칭
- 설정값
  - 전체 발언 시간
  - 턴당 제한
  - 오버타임 기준
  - 알림 설정
- 결과값
  - 사용한 시간
  - 오버타임 합계
  - 패널티 횟수
  - 휴식 횟수
- 메모

### 액션
- 삭제
- 같은 설정으로 다시 시작

## 11. App Settings Screen
### 목적
앱 기본값을 관리한다.

### 섹션
- 기본 시간 설정
  - 전체 발언 시간 기본값
  - 전체 시간 모드 기본값
  - 턴당 제한 기본값
- 오버타임/패널티
  - 오버타임 기본값
  - 패널티 기준 기본값
  - 반복 패널티 기본값
- 알림
  - 사전 알림 시점
  - 화면 표시
  - 소리
  - 진동/햅틱
- 기록
  - 기록 자동 저장 여부
  - 모든 기록 삭제
- 개인정보
  - 로컬 저장 안내
  - 개인정보 처리방침

## 12. 접근성 고려
- 숫자는 크게 표시한다.
- 색상만으로 상태를 전달하지 않는다.
- 오버타임/패널티 상태는 텍스트로도 표시한다.
- 진동을 사용할 수 없는 사용자에게 화면 알림을 제공한다.
- 소리를 듣기 어려운 사용자에게 시각 알림을 제공한다.
- 버튼은 충분히 크게 만든다.
