# 04. Screen Specs

## 1. Home Screen
### 목적
사용자가 빠르게 대화 세션을 시작한다.

### 구성
- 앱 로고/이름
- 큰 버튼: “새 대화 시작”
- 작은 버튼: “5분씩 빠른 시작”
- 최근 기록 카드 1~3개
- 설정 아이콘

### 카피
- 제목: “말할 차례를 나눠볼까요?”
- 설명: “서로의 시간을 지키며 대화할 수 있어요.”

### 액션
- 새 대화 시작 → New Session
- 빠른 시작 → Consent
- 최근 기록 → History Detail

## 2. New Session Screen
### 목적
대화의 기본 규칙을 설정한다.

### 필드
- 대화 유형: 부부/연인, 가족, 회의, 토론, 직접 설정
- 참가자 A 이름
- 참가자 B 이름
- 시간 프리셋
- 모드: 총량 모드 / 라운드 모드

### 기본값
- 참가자 이름: 나 / 상대
- 시간: 각 5분
- 모드: 총량 모드

### 유효성
- 이름은 비어도 가능하되 기본값 사용
- 시간은 최소 1분, 최대 30분

## 3. Consent Screen
### 목적
앱 사용이 양쪽 합의로 시작됨을 보장한다.

### 구성
- 규칙 카드
- 참가자 A 동의 버튼
- 참가자 B 동의 버튼
- 시작 버튼

### 규칙 문구
- “말하는 사람의 시간이 줄어듭니다.”
- “말이 끝나면 차례를 넘겨주세요.”
- “누구든 휴식을 누를 수 있습니다.”
- “이 앱은 승패를 정하지 않습니다.”

### 시작 조건
- 두 동의 버튼이 모두 활성화되어야 시작 가능

## 4. Timer Screen
### 목적
대화 시간을 직관적으로 관리한다.

### 레이아웃
- 화면을 두 영역으로 분할
- 각 영역에 이름, 남은 시간, 상태 표시
- 중앙 또는 하단에 주요 버튼

### 상태
- 대기 중
- A 발언 중
- B 발언 중
- 휴식 중
- 종료됨

### 버튼
- A가 말하기
- B가 말하기
- 차례 넘기기
- 휴식
- 종료

### 알림
- 30초 남음: 작은 진동 또는 시각 안내
- 10초 남음: 부드러운 알림
- 0초: 종료 안내

## 5. Break Screen
### 목적
감정이 올라왔을 때 멈출 수 있게 한다.

### 구성
- “잠깐 쉬어도 괜찮아요.”
- “지금은 해결보다 진정이 먼저일 수 있어요.”
- 재개 버튼
- 오늘은 여기까지 버튼

### 재개 조건
- MVP 기본값: 양쪽 동의 후 재개

## 6. Wrap-up Screen
### 목적
대화를 끝내고 결론을 가볍게 정리한다.

### 필드
- 종료 사유
- 합의한 것
- 남은 것
- 다음 대화 주제
- 다음 대화 날짜: v1.1 이후 가능

### 카피
- “오늘 정한 것 하나만 적어도 충분해요.”

## 7. History List Screen
### 목적
이전 대화 기록을 본다.

### 카드 정보
- 날짜
- 대화 유형
- 총 대화 시간
- A/B 사용 시간
- 메모 일부

## 8. History Detail Screen
### 목적
세션 결과를 확인하고 삭제한다.

### 표시 정보
- 참가자명
- 시작/종료 시간
- 각자 사용 시간
- 휴식 횟수
- 합의/남은 주제

### 액션
- 삭제
- 복제해서 새 세션 시작

## 9. Settings Screen
### 목적
사용자 기본값과 개인정보를 관리한다.

### 항목
- 기본 시간
- 알림음/진동
- 큰 글씨 모드
- 모든 기록 삭제
- 개인정보 안내
- 문의하기

## 디자인 톤
- 색상: 부드럽고 중립적인 톤
- 경쟁적 빨강/파랑 대비는 피한다.
- “승리/패배/점수” 단어는 쓰지 않는다.
- 버튼은 크게, 텍스트는 짧게.
